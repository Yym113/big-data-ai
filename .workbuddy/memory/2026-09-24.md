## 经验
- 用 html.parser 做「标签闭合 + 锚点 + 本地链接 + 中文标识符」四项自检，成本低、能替代人眼通读，值得固化成复用脚本。
- PowerShell 里 `if (...) {...} else {...} | Out-File` 会解析失败；改成 `$x = ...; "..." | Out-File` 顺序写法即可。
- PowerShell 捕获 Python 的 stdout 时按代码页解码，中文会乱码 → 先设 `[Console]::OutputEncoding = [System.Text.Encoding]::UTF8` 可解。
