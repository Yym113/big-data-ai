## 修复 04.ipynb 的 ModuleNotFoundError: No module named 'pandas'

**根因**：VS Code Jupyter 用的是系统 Python `C:\Users\lenovo-mr\AppData\Local\Programs\Python\Python312\python.exe`（3.12.10），该环境装了 ipykernel 但没装数据科学包。代码本身没错。

**踩坑记录**：
1. 用户机 `pip.ini` 配了多源（清华 + 阿里 + ustc），且 `--index-url` 也无法完全覆盖，pip 实际走了 **ustc 源**。第一次装 pandas 时网速仅 13.6 kB/s，下载中断 → `THESE PACKAGES DO NOT MATCH THE HASHES`（实为文件没下完，不是源被篡改）。

**给用户的关键动作**：VS Code 里要点 Jupyter 工具栏的「重启」重启内核，否则旧内核仍会报同样的错。
