## 经验
- 本机 sandbox 下 PowerShell 的 stdout 不回显，必须 `Out-File` 到临时文件再用 Read 打开。
- 中文 commit message 用 Write 工具写无 BOM 的 UTF-8 文件 + `git commit -F`，避免编码乱掉。
- ⚠️ **push 网络抖动有解**：首次 `git push` 报 `fatal: unable to access ... Recv failure: Connection was reset`（GitHub 直连被重置）。
  改用 `git -c http.version=HTTP/1.1 -c http.postBuffer=524288000 push origin main` **一次就过**。
  → 以后 push 失败先加这两个 `-c` 参数重试（不改全局配置），成功标志是输出里出现 `xxx..yyy  main -> main`。
