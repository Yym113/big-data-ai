# concept-unpacker（概念拆解器）

## 适用场景

- 想系统学一个**陌生**概念（不是已经会的内容）
- 需要一份「能讲给别人听、也能复习给自己看」的中文整理资料
- 不愿意只信单一搜索结果，要求每条结论都能指向**具体、可打开**的来源

## 不适用

- 已经是自己熟悉领域的内容（直接读专著更快）
- 高时效的事实（股市行情、政策最新变化等，请配合一手资料）
- 单一事实问答（比如「某 API 怎么调」）——这不是「概念学习」

## 输入

调用时给出：

- **概念名**（必填，字符串）：如 `Agent`、`Transformer`、`RAG`
- **深度**（可选）：`入门` / `中等` / `深入`，默认 `入门`
- **背景**（可选）：你正在解决的真实问题、你已知的前置知识
- **特殊偏好**（可选）：比如「避开数学」「多用类比」「结合我的 big-data-ai 课程」

## 工作流（按顺序执行，不可跳步）

1. **澄清边界**：默认直接展开；若给了「深度 / 背景」，先 1 句话确认理解再动手。
2. **列出学习目标**：3-5 条，按「能向非本领域朋友讲清楚」倒推。
3. **核心问题清单**：6-10 个，按「最小工作单元 → 与外部关系 → 边界与误用」递进。
4. **结构化解释**：定义 / 最小模型 / 类比 / 关键机制 / 边界。
5. **应用场景**：2 个具体例子，贴近用户背景。
6. **概念辨析**：3-5 条「容易混淆 / 误用」的边界。
7. **自测问题**：3-5 题，每题配一行答案。
8. **可核查的参考来源**：3-7 条可点击链接（优先 Wikipedia / 官方文档 / arXiv / RFC / 标准 / 工业界一手博客）；互相矛盾的来源必须挑出来在「概念辨析」里说明。

## 输出结构

- 一份 HTML，保存到 `learning-materials/<slug>.html`
- 中文、UTF-8、内联 CSS、可直接浏览器打开
- 包含可跳转目录、关键引用块、自检清单区
- 文末固定有一节「**本次生成的核查记录**」，记录哪几条链接验证过、哪些点没核到

## 资料来源要求

- 至少 **3 条**可核查来源
- 优先：Wikipedia / 官方文档 / arXiv / 工业界一手博客 / RFC / 标准
- 互相矛盾的来源必须挑出来在「概念辨析」里说明
- 引用一律附 URL
- **禁止**：纯靠模型记忆；拼凑两条冲突来源交叉而不澄清；伪造看似合理但实际打不开的链接

## 自检清单（生成完成后逐条核对，再宣告完成）

- [ ] 每条参考链接都用 WebFetch 或浏览器访问过，返回 200（或明确说明哪条核不到）
- [ ] 没有「看似资料里有但实际不存在」的引用
- [ ] 自测题答案都在正文里有解释
- [ ] 没有「看似 AI 腔」的废话段落（说人话，不要「在当今的 AI 时代……」）
- [ ] HTML 在浏览器里打开不报错（无 404 图、无残缺布局）
- [ ] 「核查记录」段落明确写了**哪些环节是 AI 生成、哪些是人工核对**

## 不做的事

- 不会只生成一段 prompt 或一份对话截图
- 不会整段照搬 AI 对话结果到 markdown/html
- 不会隐瞒某条引用的实际核验状态
