Agent Skill 是什么？

把 Agent 从“通才”变成“专家”的小册子

01 一句话定义

Skill 是 给 Agent 看的任务说明书。它告诉 Agent：什么时候该出场、具体怎么做、需要调用哪些工具。

02 三个核心点（点击展开）

Skill 是一个目录

不是单文件，而是一个文件夹。
目录里必须包含 SKILL.md，还可以放 scripts/、references/、assets/。Agent 根据任务需要决定加载哪部分。

SKILL.md 决定触发时机

开头的 name + description 是“触发器”。
当用户说的话匹配 description 描述的场景时，Agent 就会加载这个 skill。写得不清晰，Agent 就永远不会用它。

分三级加载

省 token，也省认知负担。
① 元数据（name+description）常驻上下文；② SKILL.md 正文触发时加载；③ scripts/references/assets 按需加载。

03 目录长什么样

my-skill/
  ├── SKILL.md ← 必须。YAML 头 + 流程说明
  ├── scripts/ ← 可复用脚本（Python / Bash）
  ├── references/ ← 参考资料，按需加载
  └── assets/ ← 模板、图片等输出资源
