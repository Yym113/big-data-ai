1 · 个人理解（先说人话）

列表靠「第几个」取东西，字典靠名字取东西。 

# 列表：你得记住「第 0 个是标题，第 1 个是浏览量」—— 一周后肯定忘
news = ["AI 重塑新闻业", 12800, "科技日报"]

# 字典：名字写在代码里，不用记
news = {"标题": "AI 重塑新闻业", "浏览": 12800, "来源": "科技日报"}
print(news["标题"])     # AI 重塑新闻业

一条新闻就是一个天然的字典型数据：标题、来源、发布时间、浏览量、正文 —— 每样东西都有名字。 你之后会用字典来存一条条新闻，用列表把字典装起来。这是新闻数据最常见的建模方式，没有之一。 

news_list = [
    {"标题": "AI 重塑新闻业", "浏览": 12800, "来源": "科技日报"},
    {"标题": "算法推荐争议",  "浏览": 21000, "来源": "新闻战线"},
]

for n in news_list:
    print(f'{n["来源"]}：{n["标题"]}（{n["浏览"]}）')

字典最容易栽的地方只有一个：取一个不存在的键，程序直接崩。 

news = {"标题": "AI 重塑新闻业"}
print(news["来源"])      # KeyError: '来源'   ← 崩了
print(news.get("来源"))  # None               ← 不崩，安全
一句话记住：不确定键在不在，就用 .get()。 这一条能消掉你前期遇到的一半 KeyError。

4 · 结构化解释

4.1 定义

字典（dict）：把键映射到值的容器，也叫映射类型。 官方教程的说法：「与以连续整数为索引的序列不同，字典是以键来索引的，键可以是任何不可变类型。」

官方给出的键的限制很明确（括号里是为什么）：

  • 字符串和数字总是可以作为键；
  • 元组在仅包含字符串、数字或元组时也可以作为键；
  • 元组里直接或间接包含了任何可变对象，就不能当键；
  • 不能用列表作为键，因为列表可以用索引赋值、切片赋值或 append()、extend() 原地修改。

4.2 最小模型：一本电话簿

news = {
    "标题": "AI 重塑新闻业",
    "浏览": 12800,
    "来源": "科技日报",
}
#  键 → 值
#  "标题" → "AI 重塑新闻业"
#  "浏览" → 12800
#  "来源" → "科技日报"

官方教程用电话簿作例子：tel = {'jack': 4098, 'sape': 4139}， tel['guido'] = 4127 是「登记一个新号码」，tel['jack'] 是「查号码」。 查一个没登记过的名字，就该报错（KeyError）—— 这是合理的，因为数据就是不存在。

4.3 类比

概念类比说明
字典通讯录 / 电话簿按名字查，不用记第几行
键姓名唯一，不重复
值电话号码可以重复，可以是任何东西
d[k]查一个不存在的人查不到就当场报错（KeyError）
d.get(k)「有就给我，没有就拉倒」返回 None 或你指定的默认值
in「这个人在不在通讯录里」只问存在性，不取值
items()把通讯录一行一行念出来同时拿到键和值
键可哈希姓名得是印在封面上的固定字会自己改动的名字不能当索引（列表不行）
插入顺序通讯录是按登记先后排的3.7+ 保证顺序，但不自动按字母排

4.4 核心操作

news = {"标题": "AI 重塑新闻业", "浏览": 12800}

news["来源"] = "科技日报"      # 新增：键不存在就是新增
news["浏览"] = 13000          # 修改：键已存在就覆盖（旧值丢失）
print(news)
# {'标题': 'AI 重塑新闻业', '浏览': 13000, '来源': '科技日报'}

del news["浏览"]              # 删除键值对
print(news)                   # {'标题': 'AI 重塑新闻业', '来源': '科技日报'}

print("来源" in news)          # True   检查键是否在（不是检查值！）
print("科技日报" in news)      # False  值不在检查范围内

print(len(news))              # 2      键值对数量
in 检查的是键，不是值。想检查值要用 "科技日报" in news.values()。 这条几乎每个新手都会误解一次。

4.5 取值：d[k] vs d.get(k)

官方教程原话：「通过下标操作（d[key]）提取不存在的键的值会引发 KeyError。 要避免在试图访问可能不存在的键时遇到这种错误，可改用 get() 方法，它会在字典不存在某个键时返回 None（或指定的默认值）。」

news = {"标题": "AI 重塑新闻业", "浏览": 12800}

news["来源"]               # KeyError: '来源'
news.get("来源")           # None
news.get("来源", "未知")    # "未知"   ← 给默认值，最常用
news.get("浏览")           # 12800

# 实战：设置默认值
news["来源"] = news.get("来源", "未标注")
写法键不存在时什么时候用
d[k]抛 KeyError键必须存在（数据缺失就是 bug）
d.get(k)返回 None键可能不存在，且 None 能表达「没有」
d.get(k, 默认值)返回默认值最常用：缺失时给个合理兜底
d.setdefault(k, 默认值)插入并返回默认值想顺便把默认值写回字典时

4.6 遍历：三种方法，items() 最常用

news = {"标题": "AI 重塑新闻业", "浏览": 12800, "来源": "科技日报"}

# 方式一：只遍历键（默认行为）
for k in news:
    print(k, "=", news[k])

# 方式二：直接遍历值
for v in news.values():
    print(v)

# 方式三（官方推荐）：同时拿到键和值
for k, v in news.items():
    print(f"{k}: {v}")
# 标题: AI 重塑新闻业
# 浏览: 12800
# 来源: 科技日报
官方教程在「循环的技巧」一节里的原话是：「当对字典执行循环时，可以使用 items() 方法同时提取键及其对应的值。」 实际写代码时，只要循环体里同时用到键和值，就用 items()， 比 for k in d: v = d[k] 更短也更快。 
# 想要键的列表（按插入顺序）
list(news)
# ['标题', '浏览', '来源']
# 官方原文：「对字典执行 list(d) 操作，返回该字典中所有键的列表，按插入次序排列
#           （如需排序，请使用 sorted(d)）。」

sorted(news)
# ['来源', '标题', '浏览']   ← 按 Unicode 码位排序

4.7 键必须可哈希：这条限制在说什么

「可哈希」的意思是：这个对象有一个在其生命周期内不会变化的哈希值。 因为字典要靠哈希值快速定位，如果键能变，字典就找不着它了。 

d = {}

d["标题"] = 1        # ✅ 字符串可以
d[42] = 2            # ✅ 数字可以
d[(1, 2)] = 3        # ✅ 只含数字的元组可以
d[None] = 4          # ✅ None 可以
d[True] = 5          # ✅ bool 可以（注意 True == 1，会和上文的 1 冲突！）

d[[1, 2]] = 6
# TypeError: unhashable type: 'list'   ← 列表不行

d[{"a": 1}] = 7
# TypeError: unhashable type: 'dict'   ← 字典也不行
# 实战场景：想用「来源 + 日期」当键，怎么办？
# ❌ 列表不行
# counts[["科技日报", "2026-09-17"]] = 5

# ✅ 转成元组
counts = {}
key = ("科技日报", "2026-09-17")
counts[key] = counts.get(key, 0) + 1
print(counts)   # {('科技日报', '2026-09-17'): 1}
True == 1 且 False == 0，而且它们的哈希值相同。 所以 d[1] 和 d[True] 在字典里是同一个键。 在存布尔标记和数字计数混在一起的字典时，这会造成很难查的 bug。

4.8 插入顺序：3.7 之后是这个行为

d = {}
d["丙"] = 3
d["甲"] = 1
d["乙"] = 2

print(list(d))
# ['丙', '甲', '乙']  ← 按插入顺序，不是按字母或笔画排序

print(sorted(d))
# ['丙', '甲', '乙']  ← 这只是因为中文按 Unicode 码位恰好如此
# 想按插入顺序 → 直接用 list(d)
# 想按某种规则排序 → sorted(d, key=...) 得到新列表，原字典不动

官方文档在 dict 章节明确保留了「保持插入顺序」的保证，并说明这是语言规范的一部分（自 3.7 起）。 但「有序」不等于「会自动排序」—— 字典永远按你插入的先后排列，想要别的顺序得自己 sorted()。

4.9 遍历时不能改字典

官方教程给的策略很直接：「很难正确地在迭代多项集的同时修改多项集的内容。更简单的方法是迭代多项集的副本或者创建新的多项集。」 

# ❌ 错误：边遍历边删
users = {"Hans": "active", "Éléonore": "inactive", "景太郎": "active"}
for user in users:
    if users[user] == "inactive":
        del users[user]
# RuntimeError: dictionary changed size during iteration

# ✅ 方案一（官方示例）：迭代副本
for user, status in users.copy().items():
    if status == "inactive":
        del users[user]

# ✅ 方案二（官方示例）：创建新字典
active_users = {}
for user, status in users.items():
    if status == "active":
        active_users[user] = status

# ✅ 方案三：字典推导式（最简洁）
active_users = {u: s for u, s in users.items() if s == "active"}
注意：改值是可以的，改「键的数量」才会报错。 users[u] = "new" 在循环里合法；del users[u] 和 users[新键] = x 会抛 RuntimeError: dictionary changed size during iteration。这个区别很多人搞混。

4.10 嵌套：字典里装列表，列表里装字典

这是新闻数据最常见的两种结构，务必看熟：

# 结构 A：字典套列表 —— 一条新闻的多个标签
article = {
    "标题": "AI 重塑新闻业",
    "浏览": 12800,
    "标签": ["AI", "媒体融合", "技术"],
}
print(article["标签"][0])       # AI       先取键，再取索引
article["标签"].append("深度报道")
print(len(article["标签"]))     # 4

# 结构 B：列表套字典 —— 多条新闻
articles = [
    {"标题": "AI 重塑新闻业", "浏览": 12800, "来源": "科技日报"},
    {"标题": "算法推荐争议",  "浏览": 21000, "来源": "新闻战线"},
]
# 这是最推荐的建模方式：每一条是字典，整批是列表

# 遍历 + 提取
titles = [a["标题"] for a in articles]
total = sum(a["浏览"] for a in articles)

# 结构 C：字典套字典 —— 按来源分组
by_source = {}
for a in articles:
    src = a["来源"]
    by_source.setdefault(src, []).append(a["标题"])
print(by_source)
# {'科技日报': ['AI 重塑新闻业'], '新闻战线': ['算法推荐争议']}

setdefault(键, 默认值) 的意思是「键不在就设成默认值，然后返回这个键对应的值」， 所以它天然适合做「分组累加」—— 这一行的效果等价于写 4 行 if/else。 后面学 pandas 时，groupby 就是这件事的工业化版本。

5 · 应用场景

场景一：把一批新闻建成「列表套字典」并做统计

articles = [
    {"标题": "AI 写稿工具上线",   "浏览": 12800, "来源": "科技日报", "标签": ["AI", "产品"]},
    {"标题": "县级融媒体三周年", "浏览": 3400,  "来源": "新闻战线", "标签": ["基层"]},
    {"标题": "算法推荐争议调查", "浏览": 21000, "来源": "科技日报", "标签": ["AI", "算法"]},
    {"标题": "AI 版权第一案",    "浏览": 9600,  "来源": "法治日报", "标签": ["AI", "版权"]},
]

# 1. 用 get 安全取值：没有「标签」的条目返回空列表
for a in articles:
    tags = a.get("标签", [])
    if "AI" in tags:
        print(f'{a["标题"]}（{a["浏览"]}）')
# AI 写稿工具上线（12800）
# 算法推荐争议调查（21000）
# AI 版权第一案（9600）

# 2. 按来源统计条数与总浏览量 —— 字典累加的经典模式
stats = {}
for a in articles:
    src = a["来源"]
    if src not in stats:              # 也可以写成 stats.setdefault(src, [0, 0])
        stats[src] = [0, 0]           # [条数, 总浏览量]
    stats[src][0] += 1
    stats[src][1] += a["浏览"]

for src, (cnt, total) in stats.items():
    print(f"{src}: {cnt} 条，平均 {total / cnt:.0f}")
# 科技日报: 2 条，平均 16200
# 新闻战线: 1 条，平均 3400
# 法治日报: 1 条，平均 9600

# 3. 统计所有标签出现次数
tag_count = {}
for a in articles:
    for t in a.get("标签", []):
        tag_count[t] = tag_count.get(t, 0) + 1
print(sorted(tag_count.items(), key=lambda kv: -kv[1]))
# [('AI', 3), ('产品', 1), ('算法', 1), ('版权', 1), ('基层', 1)]
d[k] = d.get(k, 0) + 1 是「计频」的万能句式，背下来。 词频统计、来源统计、标签统计，全是这一行。后面学 collections.Counter 会看到更省的写法，但原理就是这个。

场景二：用字典维护「来源 → 网址」的对照表，做数据规整

抓下来的来源名字五花八门（「XX网」「XX新闻网」「XX新闻」），做统计前要先统一。 字典做对照表是最直接的办法。 

# 对照表：各种写法 → 规范名称
SOURCE_MAP = {
    "科技日报": "科技日报",
    "科技日报社": "科技日报",
    "科技日报网": "科技日报",
    "新闻战线": "新闻战线",
    "新闻战线杂志": "新闻战线",
}

raw = [
    {"标题": "AI 写稿工具上线", "来源": "科技日报社"},
    {"标题": "县级融媒体三周年", "来源": "新闻战线杂志"},
    {"标题": "算法推荐争议调查", "来源": "科技日报网"},
    {"标题": "某地方台报道", "来源": "某地方台"},     # 对照表里没有
]

for a in raw:
    raw_name = a.get("来源", "").strip()
    # 用 get 兜底：对照表里没有就保留原名
    a["来源规范"] = SOURCE_MAP.get(raw_name, raw_name)

for a in raw:
    print(a["来源"], "→", a["来源规范"])
# 科技日报社 → 科技日报
# 新闻战线杂志 → 新闻战线
# 科技日报网 → 科技日报
# 某地方台 → 某地方台

# 顺手统计规范后的来源分布
dist = {}
for a in raw:
    dist[a["来源规范"]] = dist.get(a["来源规范"], 0) + 1
print(dist)
# {'科技日报': 2, '新闻战线': 1, '某地方台': 1}

# 报告「没被对照表覆盖」的来源（数据质量检查）
unmapped = sorted({a["来源"] for a in raw if a["来源"] not in SOURCE_MAP})
print("未覆盖：", unmapped)     # 未覆盖： ['某地方台']

最后那一步「找出没被映射到的取值」是数据清洗里非常重要的一环 —— 它能告诉你对照表还缺什么，而不是默默把数据算错。

6 · 概念辨析

辨析 1：KeyError vs None —— get 的默认值不是万能的

news = {"标题": "AI 重塑新闻业", "浏览": None}   # 浏览量明确是「没有」

news.get("浏览")            # None   ← 键存在，值是 None
news.get("来源")            # None   ← 键不存在，也是 None

# 上面两种 None 含义完全不同，但 get 分不出来！

# 想区分，要么先判断键
if "浏览" in news:
    print("键存在，值是", news["浏览"])
else:
    print("键不存在")

# 要么用哨兵默认值
missing = object()
if news.get("浏览", missing) is missing:
    print("键不存在")
get() 会把「键不存在」和「值是 None」混成一回事。 在严格要求数据完整性的场合（比如校验抓取结果），应该用 in 判断或让 KeyError 直接抛出来， 而不是一路 get() 把问题盖住。

辨析 2：in 检查键，不检查值

news = {"标题": "AI 重塑新闻业", "来源": "科技日报"}

"来源" in news                # True    检查键
"科技日报" in news            # False   值不在检查范围
"科技日报" in news.values()   # True    要检查值得显式 .values()

# 想按值反查键（注意：值可能重复，只能找到第一个）
def find_key(d, target):
    for k, v in d.items():
        if v == target:
            return k
    return None

find_key(news, "科技日报")     # '来源'

辨析 3：键唯一 —— 重复赋值会静默覆盖

d = {"标题": "第一条", "标题": "第二条"}
print(d)        # {'标题': '第二条'}   ← 前一个被悄悄丢掉了

# 更危险的情况：从列表建字典时
pairs = [("a", 1), ("a", 2), ("a", 3)]
d = dict(pairs)
print(d)        # {'a': 3}   ← 只留下最后一个，没有任何警告

# 想保留全部，值应该用列表
d = {}
for k, v in pairs:
    d.setdefault(k, []).append(v)
print(d)        # {'a': [1, 2, 3]}

官方教程：「字典的键必须是唯一的……如果你使用已存在的键进行存储，则与该键相关联的旧值将丢失。」

辨析 4：字典「保持插入顺序」≠「有序」

d = {"z": 1, "a": 2, "m": 3}

list(d)          # ['z', 'a', 'm']   ← 插入顺序，不是字母序
sorted(d)        # ['a', 'm', 'z']   ← 要排序得显式调用

# 想按值排序取出前几名
scores = {"科技日报": 16200, "新闻战线": 3400, "法治日报": 9600}
for name, s in sorted(scores.items(), key=lambda kv: -kv[1]):
    print(name, s)
# 科技日报 16200
# 法治日报 9600
# 新闻战线 3400

辨析 5：dict.copy() 也是浅拷贝

a = {"标签": ["AI", "产品"]}
b = a.copy()               # 外层是新字典
b["新键"] = 1              # 不影响 a ✅
b["标签"].append("深度")    # 影响 a ❌（内层列表共享）
print(a)                   # {'标签': ['AI', '产品', '深度']}

# 完全隔离
import copy
b = copy.deepcopy(a)

这和列表的 a[:] 完全同理 —— 见 列表 · 辨析 3。 只要有两层以上容器嵌套，就要想一下浅拷贝够不够。

辨析 6：d.get(k, 0) + 1 vs d[k] += 1

# ❌ 直接加：第一次遇到新键就崩
counts = {}
for word in ["AI", "算法", "AI"]:
    counts[word] += 1
# KeyError: 'AI'

# ✅ 兼容写法一：get 兜底
counts = {}
for word in ["AI", "算法", "AI"]:
    counts[word] = counts.get(word, 0) + 1
print(counts)      # {'AI': 2, '算法': 1}

# ✅ 兼容写法二：setdefault
counts = {}
for word in ["AI", "算法", "AI"]:
    counts[word] = counts.setdefault(word, 0) + 1

# ✅ 兼容写法三：标准库计数器（后面会学）
from collections import Counter
print(Counter(["AI", "算法", "AI"]))   # Counter({'AI': 2, '算法': 1})

d[k] += 1 报 KeyError 是新手写词频统计时必踩的第一个坑。 三种写法都对，Counter 最省事，但前两种更通用（因为值不一定是数字）。

7 · 自测问题

Q1：d = {"a": 1}，d["b"] 和 d.get("b") 分别怎样？
d["b"] 抛 KeyError: 'b'；d.get("b") 返回 None， 写 d.get("b", 0) 则返回 0。官方教程明确说 get() 就是为避免这个问题而存在的。
Q2：为什么 d[[1,2]] = "x" 会报错，而 d[(1,2)] = "x" 不会？
字典的键必须是可哈希的（不可变）。列表是可变对象，可以用索引赋值、切片赋值、append 原地修改， 所以不能作为键；只包含不可变元素的元组可以。
Q3：遍历字典时同时拿到键和值，最推荐的写法是什么？
for k, v in d.items():。官方教程在「循环的技巧」里明确推荐用 items() 同时提取键和值。
Q4：d = {"b": 1, "a": 2}，list(d) 得到什么？这是「排序」吗？
得到 ['b', 'a']。这是插入顺序，不是排序。官方原文：list(d) 返回所有键的列表， 「按插入次序排列（如需排序，请使用 sorted(d)）」。
Q5："科技日报" in news 是在检查键还是值？
检查键。要检查值必须写 "科技日报" in news.values()。这是 in 最常见的误解。
Q6：为什么 for k in d: del d[k] 会报错？怎么改？
会抛 RuntimeError: dictionary changed size during iteration（遍历中改变了字典大小）。 安全写法：遍历 d.copy().items()，或者用字典推导式创建一个新字典 {k: v for k, v in d.items() if 条件}。
Q7：统计词频时 counts[w] += 1 为什么会崩？正确写法是什么？
新词对应的键还不存在，counts[w] 取值时就抛 KeyError。 正确写法：counts[w] = counts.get(w, 0) + 1，或用 setdefault、collections.Counter。
