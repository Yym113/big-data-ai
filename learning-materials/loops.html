1 · 个人理解（先说人话）

循环就是把同一件事重复做 N 遍。你处理一批新闻，不可能一条一条手写代码 —— 写一次，让它自己跑完。 

titles = ["AI 重塑新闻业", "算法推荐争议", "县级融媒体"]

for t in titles:
    print(t)

Python 的 for 和 C、Java 的 for 长得像但不一样。官方文档专门强调过这一点： 它是「在列表或字符串等任意序列的元素上迭代，按它们在序列中出现的顺序」，不是「从 0 数到 n」。

所以你写循环时脑子里想的应该是：「对每一条新闻，做这些事」，而不是「i 从 0 开始，每次加 1，直到 10」。 后者要用 range() 显式写出来。 

# 「对每一条新闻做」—— 直接遍历元素（推荐）
for t in titles:
    print(len(t))

# 「重复 5 次」—— 用 range
for i in range(5):
    print("第", i + 1, "次")

最容易栽的地方是 range：range(5) 给你 0、1、2、3、4，一共 5 个数，不包含 5。 官方原话是「生成的序列绝不会包括给定的终止值」。

一句话记住：区间永远左闭右开。切片是这样，range 也是这样。 range(1, 6) 是 1 到 5，五个数。

2 · 学习目标

学完这份资料，你应该能：

  1. 用 for ... in ... 遍历列表、字典、字符串，并说清它和「数数循环」的区别；
  2. 用 range(start, stop, step) 生成数列，并解释为什么 range(5) 里没有 5；
  3. 用 enumerate() 同时拿到索引和值，用 zip() 同步遍历两个序列；
  4. 区分 break（跳出整个循环）与 continue（跳过本次）；
  5. 说出为什么不能在遍历列表时删元素，并给出两种正确写法；
  6. 认识 for ... else 的语义（以及为什么很少用它），知道 while 什么时候该用。

4 · 结构化解释

4.1 定义

循环：重复执行一段代码。Python 有两种 —— for（在序列/可迭代对象上迭代）和 while（条件为真时反复执行）。

官方文档对 for 的定位（原文）： 「Python 的 for 语句不迭代算术递增数值（如 Pascal），或是给予用户定义迭代步骤和结束条件的能力（如 C）， 而是在列表或字符串等任意序列的元素上迭代，按它们在序列中出现的顺序。」

4.2 最小模型：指针从头走到尾

words = ['cat', 'window', 'defenestrate']

for w in words:
    print(w, len(w))
# cat 3
# window 6
# defenestrate 12

for w in words 做三件事：从第一个元素开始，把每个元素依次贴到名字 w 上，执行循环体； 走到末尾自动结束。你不需要管「下一个是第几个」。 

# 循环结束后，循环变量还留着最后一个值
for w in words:
    pass
print(w)        # 'defenestrate'

# 如果循环一次都没执行（遍历空列表），循环变量根本不会被创建
for x in []:
    pass
print(x)        # NameError: name 'x' is not defined
循环变量会「泄漏」到循环外面，而且空列表会让它根本不存在。 不要依赖循环外的 w 有值，这是个隐蔽的 bug 来源。

4.3 类比

概念类比说明
for x in 一堆东西把一叠稿子一张张翻过去翻完自动停，不用数
range(5)从 0 开始数 5 张数到 0,1,2,3,4 就停 —— 不含 5
enumerate()翻稿子时顺手报个编号同时给出序号和内容
zip()两条清单并排对着一行行看短的走完就停
break翻到要找的就合上文件夹走人跳出整个循环
continue这张不要，直接翻下一张跳过本次剩余部分
while「还有下一页就继续翻」条件为真就继续，不知道要翻几页时用
for...else翻完了都没找到 → 执行 else语义是「没有 break 过」

4.4 range()：唯一需要记住的「不含尾」

官方文档：「生成的序列绝不会包括给定的终止值；range(10) 生成 10 个值。」 并且指出 range() 返回的对象「在很多方面和列表的行为一样，但其实它和列表不一样…… 并没有真正生成过一个含有全部项的列表，从而节省了空间」。 

list(range(5))          # [0, 1, 2, 3, 4]
list(range(5, 10))      # [5, 6, 7, 8, 9]
list(range(0, 10, 3))   # [0, 3, 6, 9]
list(range(-10, -100, -30))   # [-10, -40, -70]   负步长
list(range(0))          # []
list(range(1, 0))       # []
list(range(5, 5))       # []  起止相同 → 空

# range 只存 start/stop/step 三个值，不占内存
import sys
sys.getsizeof(range(1000000))   # 48 字节左右，和 range(10) 一样
sys.getsizeof(list(range(1000000)))  # 约 8 MB

# range 支持索引、切片、in
r = range(0, 20, 2)
r[5]        # 10
11 in r     # False
r[:5]       # range(0, 10, 2)
r[-1]       # 18
range() 的参数必须是整数（官方原文：「参数必须是整数……如果 step 为零，ValueError 会被引发」）。 range(2.5) 抛 TypeError；range(0, 10, 0) 抛 ValueError。 
# 常见误用
for i in range(len(titles)):
    print(titles[i])          # 能跑，但不 Pythonic

for t in titles:              # ✅ 直接遍历元素
    print(t)

for i, t in enumerate(titles):   # ✅ 需要索引时用 enumerate
    print(i, t)

4.5 enumerate() 与 zip()

官方「循环的技巧」一节的原话：「在序列中循环时，用 enumerate() 函数可以同时取出位置索引和对应的值」、 「同时循环两个或多个序列时，用 zip() 函数可以将其内的元素一一匹配」。 

# enumerate
for i, v in enumerate(['tic', 'tac', 'toe']):
    print(i, v)
# 0 tic
# 1 tac
# 2 toe

# 从 1 开始编号（做报表时常用）
for i, v in enumerate(['tic', 'tac', 'toe'], start=1):
    print(i, v)

# zip
questions = ['name', 'quest', 'favorite color']
answers = ['lancelot', 'the holy grail', 'blue']
for q, a in zip(questions, answers):
    print(f'What is your {q}?  It is {a}.')

# zip 以最短的为准
list(zip([1, 2, 3], "ab"))     # [(1, 'a'), (2, 'b')]   第三个被丢掉

# zip 还能转置矩阵
matrix = [[1, 2, 3], [4, 5, 6]]
list(zip(*matrix))             # [(1, 4), (2, 5), (3, 6)]
# 官方还给了三种「按指定顺序循环」的写法
basket = ['apple', 'orange', 'apple', 'pear', 'orange', 'banana']

for f in sorted(basket):              # 排序后遍历，不改原列表
    print(f)

for f in sorted(set(basket)):         # 去重 + 排序
    print(f)

for i in reversed(range(1, 10, 2)):   # 逆序
    print(i)
# 9 7 5 3 1

4.6 break 与 continue

官方定义：「break 语句将跳出最近的一层 for 或 while 循环」、 「continue 语句将继续执行循环的下一次迭代」。 

# break：找到就停
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            print(f"{n} equals {x} * {n//x}")
            break              # 只跳出内层！
# 4 equals 2 * 2
# 6 equals 2 * 3
# 8 equals 2 * 4
# 9 equals 3 * 3

# continue：跳过本次剩余语句
for num in range(2, 10):
    if num % 2 == 0:
        print(f"Found an even number {num}")
        continue               # 不再执行下面的 print
    print(f"Found an odd number {num}")
break 只跳出「最近的一层」循环。 双层嵌套里要跳出两层，得用标志变量、把内层抽成函数用 return，或者 for ... else 的变通写法。这是新手写双重循环时最常见的误解。

4.7 循环里不能改列表（最重要的坑）

官方教程原话：「很难正确地在迭代多项集的同时修改多项集的内容。更简单的方法是迭代多项集的副本或者创建新的多项集。」 

nums = [1, 2, 2, 3, 2, 4]

# ❌ 边遍历边删
for n in nums:
    if n == 2:
        nums.remove(n)
print(nums)          # [1, 2, 3, 4]   ← 还剩一个 2！

# 为什么：删掉一个之后，后面元素整体前移，
# 迭代器却已经"走过"那个位置，于是漏看了紧接着的那个 2

官方给出的官方思路是「迭代副本」或「创建新多项集」。三种可行写法：

# ✅ 方案一：创建新列表（官方教程推荐，最清晰）
nums = [1, 2, 2, 3, 2, 4]
nums = [n for n in nums if n != 2]
print(nums)          # [1, 3, 4]

# ✅ 方案二：整体切片替换（官方 FAQ 给出的写法，原地改）
nums = [1, 2, 2, 3, 2, 4]
nums[:] = [n for n in nums if n != 2]

# ✅ 方案三：倒着遍历删除（索引不会错位）
nums = [1, 2, 2, 3, 2, 4]
for i in range(len(nums) - 1, -1, -1):
    if nums[i] == 2:
        del nums[i]
print(nums)          # [1, 3, 4]
# 官方「过滤异常值」示例：不在循环里删，而是收集到新列表
import math
raw_data = [56.2, float('NaN'), 51.7, 55.3, 52.5, float('NaN'), 47.8]
filtered_data = []
for value in raw_data:
    if not math.isnan(value):
        filtered_data.append(value)
print(filtered_data)
# [56.2, 51.7, 55.3, 52.5, 47.8]

4.8 遍历字典时的修改（官方给了两种标准答案）

users = {'Hans': 'active', 'Éléonore': 'inactive', '景太郎': 'active'}

# ❌ 直接删：RuntimeError: dictionary changed size during iteration
for user in users:
    if users[user] == 'inactive':
        del users[user]

# ✅ 策略一（官方示例）：迭代副本
for user, status in users.copy().items():
    if status == 'inactive':
        del users[user]
print(users)   # {'Hans': 'active', '景太郎': 'active'}

# ✅ 策略二（官方示例）：创建新字典
users = {'Hans': 'active', 'Éléonore': 'inactive', '景太郎': 'active'}
active_users = {}
for user, status in users.items():
    if status == 'active':
        active_users[user] = status
print(active_users)

改值是允许的（users[u] = "new"），改键的数量才报错（增、删键）。 这个区别很多人搞混。

4.9 while 与 for ... else

# while：不知道要循环几次时用
attempts = 0
while attempts < 3:
    attempts += 1
    print("第", attempts, "次尝试")

# while True + break：必须先想好退出条件，否则死循环
while True:
    line = input("输入内容（q 退出）：")
    if line == "q":
        break
    print("你输入了：", line)

# 官方给出的 pass 用法：无限等待键盘中断
while True:
    pass   # 按 Ctrl+C 中断
# for ... else：循环「没有 break 过」才执行 else
# 官方示例：找质数
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            print(n, 'equals', x, '*', n//x)
            break
    else:
        # 循环到底未找到一个因数
        print(n, 'is a prime number')
# 2 is a prime number
# 3 is a prime number
# 4 equals 2 * 2
# 5 is a prime number
# ...
官方在这里专门加了一句提醒：「（对，这是正确的代码。 仔细看：其中 else 子句属于 for 循环， 而不属于 if 语句。）」 因为 else 的缩进和 for 对齐 —— 这个视觉陷阱让很多人第一次读错。

官方对 else 语义的解释（原文）：

「当配合循环使用时，else 子句更像是 try 语句的 else 子句而不像 if 语句的相应子句： 一个 try 语句的 else 子句会在未发生异常时运行，而一个循环的 else 子句会在未发生 break 时运行。」

入门阶段读得懂就行，不建议写。同样的逻辑用「找到就 return」的函数或标志变量写出来，可读性好得多。

5 · 应用场景

场景一：批量处理新闻列表并汇总统计

articles = [
    {"标题": "AI 写稿工具上线",   "浏览": 12800, "来源": "科技日报", "字数": 1200},
    {"标题": "县级融媒体三周年", "浏览": 3400,  "来源": "新闻战线", "字数": 860},
    {"标题": "算法推荐争议调查", "浏览": 21000, "来源": "科技日报", "字数": 3400},
    {"标题": "AI 版权第一案",    "浏览": 9600,  "来源": "法治日报", "字数": 2100},
]

total_views = 0
total_words = 0
by_source = {}

for i, a in enumerate(articles, start=1):
    views = a.get("浏览", 0)
    words = a.get("字数", 0)
    src = a.get("来源", "未标注")

    total_views += views                       # 累加器
    total_words += words

    by_source.setdefault(src, []).append(views)

    print(f"{i:>2}. {a['标题']:<10} {views:>6} 浏览  {words:>5} 字")

print(f"\n总浏览 {total_views}，平均 {total_views / len(articles):.0f}")
print(f"总字数 {total_words}，平均每篇 {total_words // len(articles)} 字")

# 按来源汇总
for src, views in sorted(by_source.items(), key=lambda kv: -sum(kv[1])):
    print(f"{src}: {len(views)} 篇，合计 {sum(views)}")
输出示例：
 1. AI 写稿工具上线 12800 浏览   1200 字
 2. 县级融媒体三周年  3400 浏览    860 字
 3. 算法推荐争议调查 21000 浏览   3400 字
 4. AI 版权第一案     9600 浏览   2100 字

总浏览 46800，平均 11700
总字数 7560，平均每篇 1890 字
科技日报: 2 篇，合计 33800
法治日报: 1 篇，合计 9600
新闻战线: 1 篇，合计 3400
「累加器四步法」：开变量 total = 0 → 循环 → if 或取值 → total += x。 统计浏览量、字数、条数，全是这个骨架。看熟它，后面 pandas 的 groupby 就是它的自动化版本。

场景二：从新闻全文中提取所有疑似关键词

ARTICLES = [
    "AI 正在重塑新闻业。AI 写稿、AI 剪辑都已落地。",
    "关于算法推荐争议的深度报道，涉及算法透明度问题。",
    "生成式 AI 的版权问题：AI 训练数据从哪里来？",
]

KEYWORDS = ["AI", "算法", "版权", "融媒体"]

# 1. 逐篇扫描，记录每篇命中的关键词
for i, text in enumerate(ARTICLES, start=1):
    hits = []
    for kw in KEYWORDS:
        if kw in text:                 # 命中就记录
            hits.append(kw)
    if hits:
        print(f"第 {i} 篇命中：{', '.join(hits)}")
    else:
        continue                       # 没命中就跳过，不打印

# 2. 全局词频统计
freq = {}
for text in ARTICLES:
    for kw in KEYWORDS:
        count = text.count(kw)
        if count == 0:
            continue                   # 没出现的不记录，保持字典干净
        freq[kw] = freq.get(kw, 0) + count

for kw, c in sorted(freq.items(), key=lambda kv: -kv[1]):
    print(f"{kw}: {c} 次")

# 3. 找到第一条提及"版权"的报道就停下（break 的典型用法）
for i, text in enumerate(ARTICLES, start=1):
    if "版权" in text:
        print(f"首次提及版权的报道是第 {i} 篇")
        break
else:
    print("没有报道提及版权")     # 循环没 break 才会执行

注意最后那段 for ... else：找到了就 break 并打印，没找到就走到 else。 这是 else 子句最自然的用法 —— 只是入门阶段不建议主动写，读得懂即可。

6 · 概念辨析

辨析 1：break vs continue

# break：整个循环结束
for i in range(5):
    if i == 3:
        break
    print(i)
# 0 1 2

# continue：只跳过本次，继续下一轮
for i in range(5):
    if i == 3:
        continue
    print(i)
# 0 1 2 4
作用范围典型场景
break跳出最近一层整个循环找到目标就停；遇到致命错误就放弃
continue只跳过本次剩余语句过滤掉不满足条件的项，继续处理后面的
return直接结束整个函数在函数里「找到了就直接返回」，比 break 更彻底

辨析 2：for i in range(len(a)) vs for i, v in enumerate(a)

titles = ["A", "B", "C"]

# ❌ 能跑，但绕了一圈
for i in range(len(titles)):
    print(i, titles[i])

# ✅ 官方推荐：enumerate 直接给出索引和值
for i, v in enumerate(titles):
    print(i, v)

# ✅ 如果不需要索引，就不要索引
for v in titles:
    print(v)

官方在讲 range() 时说过：「要按索引迭代序列，可以组合使用 range() 和 len() … 不过大多数情况下 enumerate() 函数很方便。」

辨析 3：循环里删元素 —— 三种写法的差别

nums = [1, 2, 2, 3, 2, 4]

# ❌ 漏删
for n in nums:
    if n == 2:
        nums.remove(n)
print(nums)        # [1, 2, 3, 4]

# ✅ 列表推导式（生成新列表，nums 指向新对象）
nums = [1, 2, 2, 3, 2, 4]
nums = [n for n in nums if n != 2]

# ✅ 切片赋值（原地改，其他指向该列表的变量也能看到变化）
nums = [1, 2, 2, 3, 2, 4]
other = nums
nums[:] = [n for n in nums if n != 2]
print(other)       # [1, 3, 4]   ← other 也变了，因为是同一个列表

# ✅ 倒删（原地改，不需要额外内存）
nums = [1, 2, 2, 3, 2, 4]
for i in range(len(nums) - 1, -1, -1):
    if nums[i] == 2:
        del nums[i]
nums = [...] 和 nums[:] = [...] 的区别很重要： 前者让 nums 指向一个新列表（别人手上那份没变），后者改的是原来那个列表（所有引用它的人都会看到变化）。 官方 FAQ 把「mylist[:] = (x for x in mylist if keep_condition)」列为推荐的删除多个条目写法。

辨析 4：for 的 else 属于循环，不属于 if

for n in range(2, 5):
    for x in range(2, n):
        if n % x == 0:
            print(n, "不是质数")
            break
    else:
        print(n, "是质数")     # ← 这个 else 对齐的是内层 for，不是 if

# 输出：
# 2 是质数
# 3 是质数
# 4 不是质数

# 等价的、更好读的写法
def is_prime(n):
    for x in range(2, n):
        if n % x == 0:
            return False
    return True

官方建议的读法：把循环的 else 理解成「循环内的 if 全都失败了」—— 相当于一系列 if/if/if 之后接一个 else。

辨析 5：while 忘了让条件变化 = 死循环

# ❌ 死循环
i = 0
while i < 5:
    print(i)            # i 永远不变

# ✅ 记得推进
i = 0
while i < 5:
    print(i)
    i += 1              # 关键这一行

# ✅ 用 for 替代（更不容易写错）
for i in range(5):
    print(i)

# while True + break 的写法要保证 break 必然可达
while True:
    line = input("> ")
    if not line:        # 空了就退出
        break
能用 for 就别用 while。 for 的结束条件是自动的，不会忘；while 需要你自己维护状态，忘一次就是死循环 （在 Notebook 里表现为一直在跑，只能强制中断）。

辨析 6：zip() 以最短为准，静默丢数据

titles = ["A", "B", "C"]
views = [100, 200]

list(zip(titles, views))
# [('A', 100), ('B', 200)]   ← "C" 被悄悄丢掉了！不报错，不警告

# 想发现长度不一致，先检查
if len(titles) != len(views):
    print(f"警告：标题 {len(titles)} 条，浏览量 {len(views)} 条，不匹配")

# 想保留最长，用 zip_longest
from itertools import zip_longest
list(zip_longest(titles, views, fillvalue=None))
# [('A', 100), ('B', 200), ('C', None)]

合并两个来源的数据（标题列表 + 浏览量列表）时，一定要先核对长度。 这是数据合并时最隐蔽的一类错误 —— 不报错，只是少数了几条。

7 · 自测问题

Q1：list(range(5)) 得到什么？list(range(1, 6)) 呢？
[0, 1, 2, 3, 4] 和 [1, 2, 3, 4, 5]。 官方原文：「生成的序列绝不会包括给定的终止值」。
Q2：想同时拿到索引和元素，最推荐的写法是什么？
for i, v in enumerate(seq):。官方「循环的技巧」一节明确说 enumerate() 「可以同时取出位置索引和对应的值」。
Q3：break 和 continue 有什么区别？
break 跳出最近一层整个循环；continue 只跳过本次迭代剩下的语句，进入下一轮。
Q4：为什么 for n in nums: nums.remove(n) 会漏删？
删除元素后后面的项整体前移，但迭代器已经走过那个位置，导致紧跟其后的重复元素被跳过。 官方建议「迭代多项集的副本或者创建新的多项集」，实用做法是 nums = [n for n in nums if 条件]。
Q5：for ... else 里的 else 什么时候执行？
循环未被 break 终止时执行（自然结束才执行）。 官方指出它更像 try 的 else（未发生异常时运行），而不像 if 的 else。
Q6：zip([1,2,3], "ab") 的结果是什么？
[(1, 'a'), (2, 'b')]。zip 以最短的序列为准，多余的元素被静默丢弃，不会报错。
Q7：for x in []: pass 之后 print(x) 会怎样？
抛 NameError: name 'x' is not defined。循环体一次都没执行，循环变量从未被赋值。 循环变量只在真正迭代过之后才存在。
