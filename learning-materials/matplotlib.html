1. 个人理解（先说人话）

前面几节你已经能拿到数据、清理数据、算出结果了。但算出来的结果如果只是屏幕上的一串数字， 没有读者会看，也没有编委会会通过。新闻稿里那张「三年来某类投诉量变化」的折线图， 才是读者真正会记住的东西。

matplotlib 就是干这件事的：把数据画成图。它是 Python 数据可视化里最老牌、最基础的库， pandas 的 df.plot()、seaborn 的统计图，底层全都跑在 matplotlib 上。 学会它，等于学会了这套生态的通用底座。

你想一下自己见过的图表，其实都由同几个零件拼起来：

零件matplotlib 里的名字类比
整张画布 / 一整页纸FigureA4 纸
画布上的一个坐标系Axes纸上画的一个坐标格
坐标轴上的刻度尺Axis直尺的刻度线
图上的任何可见元素Artist纸上的线条、文字、色块

这里有个中文翻译很容易搞混的坑：Axes 不是「坐标轴」，Axis 才是。 Axes 应该理解成「一个绘图区」，一个 Axes 里通常包含两个（3D 图里三个）Axis。 官方快速入门指南专门提醒过要注意区分这两个词。

然后是最容易把人绊倒的一点：matplotlib 有两套写法。 一套是「隐式」的 plt.plot(...)，一套是「显式」的 fig, ax = plt.subplots(); ax.plot(...)。 你在网上抄代码时，十有八九会抄到两套混在一起的代码，然后一头雾水。 官方给的建议很明确：一般建议用显式（OO）那套，尤其是复杂图和要复用的脚本。

官方原话：「Overall, it is useful to understand the explicit "Axes" interface since it is the most flexible and underlies the other interfaces.」（理解显式 Axes 接口很有用，因为它最灵活，而且是其他接口的底层。） 同时官方也承认：「While the explicit interface can be a bit more verbose to setup, complicated plots will often end up simpler than trying to use the implicit "pyplot" interface.」 （显式接口起步时啰嗦一些，但复杂图形往往反而更简单。）

2. 学习目标

学完这一节，你应该能做到：

  1. 说清 Figure、Axes、Axis、Artist 四者的关系，不再把 Axes 当「坐标轴」。
  2. 用 fig, ax = plt.subplots() 写出一张带标题、轴标签、图例的折线图或者柱状图。
  3. 知道 plt.plot()（隐式）和 ax.plot()（显式）怎么互相翻译，能读懂两种风格的代码。
  4. 能解决中文显示成方块的问题——知道为什么要设 font.family，知道 Windows 和 macOS 该填什么字体名，知道怎么查自己电脑上有什么字体。
  5. 知道 show() 和 savefig() 的调用顺序，不会存出一张空白图。
  6. 知道 savefig() 的 dpi、bbox_inches、format 三个参数各管什么，能导出一张能印的图。
  7. 知道 pandas 的 df.plot() 和 matplotlib 是什么关系，什么时候直接用 pandas、什么时候必须回到 matplotlib。
  8. 知道什么图该配什么数据（折线 vs 柱状 vs 散点），不犯「用饼图比较 12 个类别」这种低级错。

4. 结构化解释

4.1 定义：它到底是什么

matplotlib 是一个绘图库。官方快速入门指南对它的核心概念给了这样一段定义，值得逐字读一遍：

「Matplotlib plots data on Figures (e.g. windows, Jupyter widgets, etc.), each of which can contain one or more Axes, an area where points can be specified in terms of x-y coordinates (or theta-r in a polar plot, or x-y-z in a 3D plot, etc.). The simplest way of creating a Figure with an Axes is using pyplot.subplots. We can then use Axes.plot to draw some data on the Axes, and show to display the figure.」

翻译成人话：数据画在 Figure 上；Figure 里可以有一个或多个 Axes；Axes 是「可以用坐标指定点的区域」。 创建带 Axes 的 Figure 最简单的方式是 pyplot.subplots，然后用 Axes.plot 画数据， 用 show 显示。

官方对四个零件的定义分别如下（均引自快速入门指南）：

名字官方定义（意译）你可以怎么记
Figure 「The whole figure. The Figure tracks all the child Axes, a bunch of 'special' Artists (titles, figure legends, colorbars, etc.), and even nested subfigures.」
整张图。Figure 跟踪所有子 Axes、一组「特殊」Artist（标题、图形图例、颜色条等），甚至嵌套的子图。		 一整张纸，管着纸上所有的图
Axes 「An Axes is an Artist attached to a Figure that contains a region for plotting data, and usually includes two (or three in the case of 3D) Axis objects」
Axes 是挂在 Figure 上的一个 Artist，包含用于绘制数据的区域，通常还包括两个（3D 时三个）Axis 对象。		 一个绘图区；不是坐标轴
Axis 「These objects set the scale and limits and generate ticks (the marks on the Axis) and ticklabels」
设置比例和范围，生成刻度（轴上的标记）和刻度标签。刻度位置由 Locator 决定，标签字符串由 Formatter 格式化。		 那把刻度尺
Artist 「Basically everything visible on the Figure is an Artist (even the Figure, Axes, and Axis objects).」
Figure 上所有可见的东西都是 Artist，连 Figure、Axes、Axis 自己都是。		 纸上任何你看得见的东西

官方还特别强调了一句关于 Axes 的地位：「Axes methods are the primary interface for configuring most parts of the plot」——Axes 上的方法就是配置图形绝大部分内容的主接口（加数据、控制坐标轴比例和范围、加标签）。 这句话解释了为什么下面 4.3 节一直推荐你用 ax.xxx()。

4.2 最小模型：一张能跑的最小图

官方给出的最小示例，只有四行（注释是官方原文）：

import matplotlib.pyplot as plt
import numpy as np

fig, ax = plt.subplots()             # Create a figure containing a single Axes.
ax.plot([1, 2, 3, 4], [1, 4, 2, 3])  # Plot some data on the Axes.
plt.show()                           # Show the figure.

这四行是这一整节的骨架。注意官方注释里那句「Create a figure containing a single Axes」—— subplots()（复数，带 s）一次帮你把「纸」和「绘图区」都建好并递到你手里。 而单数的 plt.subplot(1, 2, 1) 是「切一个子图并把它设为当前」，两者不是一回事。

把这四行扩成一张新闻稿能用的图，加上标题、轴标签、图例：

import matplotlib.pyplot as plt

x = [2021, 2022, 2023, 2024, 2025]
complaints = [1200, 1580, 1420, 2100, 2650]

fig, ax = plt.subplots(figsize=(6, 3.6))   # 纸的大小，单位英寸
ax.plot(x, complaints, marker="o", label="某类消费投诉量")
ax.set_xlabel("年份")
ax.set_ylabel("件数")
ax.set_title("近五年某类消费投诉量变化")
ax.legend()          # 图例内容来自 plot() 里的 label=
plt.show()
这时候中文全是方块。别急，4.5 节专门处理。 这里先记住一件事：图的逻辑和中文显示是两个独立问题，先让逻辑跑通，再修字体。

4.3 关键机制一：两套接口怎么互相翻译

官方文档把两套接口叫「显式 Axes 接口」和「隐式 pyplot 接口」：

「An explicit "Axes" interface that uses methods on a Figure or Axes object to create other Artists, and build a visualization step by step. This has also been called an "object-oriented" interface.」
显式 Axes 接口：通过在 Figure 或 Axes 对象上调用方法，一步步构建可视化。也叫「面向对象」接口。

「An implicit "pyplot" interface that keeps track of the last Figure and Axes created, and adds Artists to the object it thinks the user wants.」
隐式 pyplot 接口：记住最近创建的 Figure 和 Axes，把 Artist 加到「它以为你想要」的那个对象上。

最后半句是重点：「加到它以为你想要的那个对象上」。 这就是为什么隐式写法一旦图多了就会出乱子——你以为是画在 A 图上，实际画到了 B 图上。

官方给的对照表（抄录如下）：

操作Axes 接口（显式，推荐）pyplot 接口（隐式）
创建图形fig, ax = plt.subplots()plt.subplots()
画数据ax.plot(x, y)plt.plot(x, y)
取属性label = ax.get_xlabel()label = plt.xlabel()
设属性ax.set_xlabel("time")plt.xlabel("time")

规律很清楚：画图函数两边名字完全一样（plot 就是 plot）； 取属性的在 Axes 上前缀 get_，设属性的前缀 set_。 你在网上看到的 plt.title("xx")，翻译过来就是 ax.set_title("xx")。

官方还举了一个「同样一张双轴图，三种写法」的例子，非常能说明问题：

# 隐式写法一：完全不管对象
plt.subplot(1, 2, 1)
plt.plot([1, 2, 3], [0, 0.5, 0.2])

plt.subplot(1, 2, 2)
plt.plot([3, 2, 1], [0, 0.5, 0.2])

# 隐式写法二：靠 gca()（get current axes）去捞当前轴
plt.subplot(1, 2, 1)
ax = plt.gca()
ax.plot([1, 2, 3], [0, 0.5, 0.2])

plt.subplot(1, 2, 2)
ax = plt.gca()
ax.plot([3, 2, 1], [0, 0.5, 0.2])

# 显式写法（官方推荐）
fig, axs = plt.subplots(1, 2)
axs[0].plot([1, 2, 3], [0, 0.5, 0.2])
axs[1].plot([3, 2, 1], [0, 0.5, 0.2])

官方给了一个特别真实的场景来说明显式写法为什么好——「如果你想回头改一个已经不在 plt.gca() 里的旧轴怎么办？」 官方列了两种「凑合的办法」：再次调用 plt.subplot 传一样的参数；或者自己存一个 handle 列表然后用 plt.sca() 切回去。 官方对第一种的评价是 「However, that quickly becomes inelegant.」（很快就变得不优雅了）， 对第二种的评价是 「but if you do that, why not simply create all the Axes objects at the start?」 （既然都要存 handle 了，为什么不一开始就把所有 Axes 都创建出来？）

结论：默认就用 fig, ax = plt.subplots() 这一套。 只有在你做探索性的一行行试算、或者写三行的临时脚本时，才用 plt.plot() 图省事。

顺便，官方明确点名了一个必须避开的写法：

「There is one further interface that is highly discouraged, and that is to basically do from matplotlib.pylab import *. ... Such a pattern is considered bad practice in modern python, as it clutters the global namespace. Even more severely, in the case of pylab, this will overwrite some builtin functions (e.g. the builtin sum will be replaced by numpy.sum), which can lead to unexpected behavior.」

人话：别用 from matplotlib.pylab import *。它会把内置的 sum 偷换成 numpy.sum，导致一些莫名其妙的 bug。老教程里看到这种写法，绕开。

4.4 关键机制二：中文方块是怎么来的，怎么修

这是零基础同学第一个必然撞上的墙，也是这一节最重要的一块。官方文档把原因说得很清楚：

「As of v2.0 the default font, DejaVu, contains glyphs for many western alphabets, but not other scripts, such as Chinese, Korean, or Japanese.」
从 v2.0 起，默认字体 DejaVu 包含许多西方字母的字形，但不包含中文、韩文、日文等其他文字。

所以方块不是「乱码」，也不是编码问题——是 字体里根本没有这个汉字长什么样。 渲染器找不到字形，只好画个空心方框占位。这也解释了为什么有些字正常、有些字是方块： 通常是一整片中文全变方块，而同一串里的英文数字正常。

官方给的第一种改法（推荐）：把中文字体名加到 font.family 的最前面。

# first method
matplotlib.rcParams['font.family'] = ['Source Han Sans TW', 'sans-serif']

官方给的第二种改法：改「通用族名」对应的具体字体列表。

# second method
matplotlib.rcParams['font.family'] = ['sans-serif']
matplotlib.rcParams['sans-serif'] = ['Source Han Sans TW', ...]

这里的原理，官方在「默认字体」一节解释得很细：font.family 接受的是 「用户机器上已安装的字体族名」和/或 {'cursive', 'fantasy', 'monospace', 'sans', 'sans serif', 'sans-serif', 'serif'} 这些通用族名这两类东西。 而通用族名到具体字体的映射，由另外几个 rcParam 控制：

通用族别名对应的 rcParam（映射表）
'serif''font.serif'
'monospace''font.monospace'
'fantasy''font.fantasy'
'cursive''font.cursive'
{'sans', 'sans serif', 'sans-serif'}'font.sans-serif'

官方还给了一段「替换规则」的说明和一个例子，看懂它你就明白第一种改法和第二种改法为什么等价：

「If any of generic family names appear in 'font.family', we replace that entry by all the entries in the corresponding rcParam mapping.」 
matplotlib.rcParams['font.family'] = ['Family1', 'serif', 'Family2']
matplotlib.rcParams['font.serif'] = ['SerifFamily1', 'SerifFamily2']

# This is effectively translated to:
matplotlib.rcParams['font.family'] = ['Family1', 'SerifFamily1', 'SerifFamily2', 'Family2']

也就是说：你在 font.family 里写的 'serif' 会被原地展开成 font.serif 那一整串具体字体。所以「第一种方法」和「第二种方法」本质是在改同一张表， 只是改的位置不同。

官方还有一条很实用的实践建议：

「A good practice when setting custom font families is to append a generic-family to the font-family list as a last resort.」
设自定义字体时，最好在列表最后加一个通用族名兜底。 比如 ['Microsoft YaHei', 'sans-serif']——万一这台机器没有微软雅黑，至少还有 sans-serif 兜着， 不至于连英文都画不出来。

4.5 关键机制三：Windows 和 macOS 该填什么字体名

官方文档有一句非常诚实的话，解释了为什么没有一份「万能字体配置」可以直接抄：

「Matplotlib can use font families installed on the user's computer, i.e. Helvetica, Times, etc.」
matplotlib 用的是你电脑上已安装的字体族。所以同一份代码，在你电脑上正常、在同事电脑上变方块，是完全可能的。

先解决最要紧的事：怎么知道我这台机器上有哪些中文字体？

官方给了一个方法（这是替代老教程里那个已经过时的 font_manager.fontManager.ttflist 写法的现役 API）：

matplotlib.font_manager.get_font_names()   # 返回当前可用字体名的完整列表

把结果打印出来，搜索中文常见字体名，看到什么就填什么。注意：必须填「字体族名」，不能填文件路径。

官方在 Linux 上给的排查示范是 fc-list，用来列出支持中文的字体：

$ fc-list :lang=zh family
Noto to Sans Mono CJK TC,Noto Sans Mono CJK TC Bold
Noto Sans CJK TC,Noto Sans CJK TC Medium
Noto Sans CJK TC,Noto Sans CJK TC DemiLight
Noto Sans CJK KR,Noto Sans CJK KR Black
Noto Sans CJK TC,Noto Sans CJK TC Black
Noto Sans Mono CJK TC,Noto Sans Mono CJK TC Regular
Noto Sans CJK SC,Noto Sans CJK SC Light

这个例子的输出格式很有信息量：逗号前是族名，逗号后是具体的 face（字重/风格）。 比如 Noto Sans CJK TC,Noto Sans CJK TC Bold 这一行，族名是 Noto Sans CJK TC， 你往 font.family 里填的应该是前者（族名），不是 Noto Sans CJK TC Bold（那是某个字重）。 填错会出现「明明装了字体但报找不到字体」的怪事。

三个平台的具体做法，都基于同一条规则——把中文字体名写在 font.family 列表的最前面：

平台常见中文字体族名写法
Windows Microsoft YaHei（微软雅黑）、SimHei（黑体）、SimSun（宋体）、KaiTi（楷体） plt.rcParams['font.family'] = ['Microsoft YaHei', 'SimHei', 'sans-serif']
macOS PingFang SC（苹方）、Hiragino Sans GB（冬青黑体）、Heiti SC、STHeiti plt.rcParams['font.family'] = ['PingFang SC', 'Hiragino Sans GB', 'sans-serif']
Linux Noto Sans CJK SC、Source Han Sans TW（思源黑体）、WenQuanYi Micro Hei（文泉驿微米黑） plt.rcParams['font.family'] = ['Noto Sans CJK SC', 'sans-serif']
这里必须说清楚一件事：上表里的 Windows / macOS 字体名和具体写法， 不是 matplotlib 官方文档给出的明文（官方文档的例子用的是 Linux 上的 Noto / Source Han）。 这一部分是依据官方「font.family = 具体字体族名列表」这条规则推出的常见配置， 请你在自己机器上用 get_font_names() 核实一遍再用。 好在即使字体名填错，因为有 'sans-serif' 兜底，代码也不会崩，只是中文继续显示方块—— 所以「中文还是方块」这个症状，第一嫌疑就是字体名填错了。

另外官方给了一个「一次设好、整段脚本生效」的写法，还有写进配置文件的做法：

# 在脚本最开头（import 之后立刻）设，后续所有图都生效
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = ['Microsoft YaHei', 'sans-serif']
plt.rcParams['axes.unicode_minus'] = False   # 顺带解决负号显示成方块的问题

# 或者写进 .matplotlibrc 配置文件，全局永久生效：
# font.family: Source Han Sans TW, Arial, sans-serif

上面那行 axes.unicode_minus 是很多老教程都会带的一句。诚实标注：它不在本次核实的来源页里 （官方「Fonts in Matplotlib」和「Text properties」两页都没提到这个参数）， 所以请把它当成一个「社区常见经验」而非官方要求。如果你设了中文字体之后 y 轴负号变成方块，可以加上试试。

还有一件很值得知道的事：从 Matplotlib 3.6 起，同一段文字内部可以混用多种字体。 官方给的例子（把中英混排的字符串交给一串字体，每个字形用「列表里第一个有它的字体」来渲染）： 

fig, ax = plt.subplots()
ax.text(
    .5, .5, "There are 几个汉字 in between!",
    family=['DejaVu Sans', 'Noto Sans CJK JP', 'Noto Sans TC'],
    ha='center'
)

官方对这个机制的解释是：「Each glyph of the string is rendered using the first font in the list that contains that glyph.」——每个字形用列表里第一个包含它的字体来渲染。 在 3.6 之前，一个 Text 实例只能用一种字体，所以「中英混排要显示正确」曾经很折腾。 现在你只需要给 family= 传一个列表就行。注意这个能力对 Agg、SVG、PDF、PS 后端都有效。

修中文的完整流程，三步：
  1. 先确认方块是「字体缺字形」而不是「编码错误」——如果你是在脚本里读文件，先确认文件读进来是对的（见 file-io 那节）。
  2. matplotlib.font_manager.get_font_names() 查出你机器上真实的中文字体族名。
  3. 把族名写在 plt.rcParams['font.family'] 列表最前面，末尾留一个 'sans-serif' 兜底。

4.6 关键机制四：show() 和 savefig() 的顺序（存出空白图的真相）

这是第二个几乎人人都会撞的墙。官方在 pyplot.show() 的文档里专门开了一节讲这件事， 标题就是「Saving figures to file and showing a window at the same time」，原文如下：

「If you want an image file as well as a user interface window, use pyplot.savefig before pyplot.show. At the end of (a blocking) show() the figure is closed and unregistered from pyplot. Calling pyplot.savefig afterwards would save a new and thus empty figure. This limitation does not apply if show is non-blocking; or if you keep a reference to the figure and use Figure.savefig instead of pyplot.savefig.」

拆成三句人话：

  1. 想要文件又要看窗口，就先 savefig() 再 show()。
  2. 阻塞式 show() 结束时，图会被关闭并从 pyplot 注销。这时候再调 pyplot.savefig()，它去 pyplot 里找「当前图」，找不到旧的就新建一张空图，于是你存出一个白板。
  3. 这个限制不适用于两种情况：show 是非阻塞的；或者你自己留了 figure 引用、 改用 Figure.savefig（也就是 fig.savefig()）而不是 pyplot.savefig。
# ❌ 错误顺序：存出来是一张空白图
plt.show()
plt.savefig("投诉趋势.png")

# ✅ 正确顺序
plt.savefig("投诉趋势.png")
plt.show()

# ✅ 另一条安全路线：用 fig.savefig()，顺序就不那么要紧了
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 4, 2])
fig.savefig("投诉趋势.png")   # 注意是 fig. 不是 plt.
plt.show()

第 3 条里的「保留引用 + 用 fig.savefig()」这条路，正好和 4.3 节推荐的显式接口对上—— 你用显式接口，顺手就拿到了 fig，于是这个坑天然绕过去了。 这是「推荐显式接口」的一个很实际的好处。

另外 show() 本身还有一个参数值得知道：

参数含义默认值
block 是否等到所有图形窗口都关掉才返回。True 会阻塞并运行 GUI 主循环； False 会确保窗口显示后立即返回，此时你需要自己保证事件循环在跑，图才保持可响应。 非交互模式为 True；交互模式为 False（交互模式状态见 pyplot.isinteractive）

签名是 matplotlib.pyplot.show(*, block=None)——注意那个 *，block 是 仅关键字参数，必须写成 plt.show(block=False)，不能写 plt.show(False)。

还有一个环境差异：

「Depending on the environment you are working in, plt.show() can be left out. This is for example the case with Jupyter notebooks, which automatically show all figures created in a code cell.」
在 Jupyter 里，plt.show() 可以省掉，它会自动显示每个单元格里创建的所有图。官方还补充说， Jupyter 后端（通过 %matplotlib inline、%matplotlib notebook 或 %matplotlib widget 激活）默认会在每个 cell 结束时调用 show()，所以通常不需要显式调用。
一句总结：在脚本里跑（python xxx.py）就写 plt.show()； 在 Jupyter 里想省就省。不管在哪，savefig 永远写在 show 前面，或者直接用 fig.savefig()。

4.7 关键机制五：savefig() 的三个关键参数

官方签名（注意 fname 之后是 *，其余参数全部仅关键字）：

savefig(fname, *, transparent=None, dpi='figure', format=None,
        metadata=None, bbox_inches=None, pad_inches=0.1,
        facecolor='auto', edgecolor='auto', backend=None,
        **kwargs
       )

对新闻出图，最要紧的是这三个：

参数官方说明（摘）你该怎么填
dpi float 或 'figure'，默认 rcParams["savefig.dpi"]（默认值 'figure'）。「The resolution in dots per inch. If 'figure', use the figure's dpi value.」——每英寸点数（分辨率）。填 'figure' 就用图形自己的 dpi。 屏幕/网页用默认或 150；要送去印刷用 300。不要以为调大 dpi 能救一张低质量图——它只是把同一张图放大输出。
bbox_inches str 或 Bbox，默认 rcParams["savefig.bbox"]（默认 None）。「Bounding box in inches: only the given portion of the figure is saved. If 'tight', try to figure out the tight bbox of the figure.」——以英寸为单位的包围盒，只保存给定部分；填 'tight' 会试着算出紧凑包围盒。 填 "tight"。这是解决「标题被切掉一半」「x 轴标签跑出画布」的标准做法。
format str，如 'png'、'pdf'、'svg'。若已设置，输出格式由它决定，文件按 fname 保存。 见下面那条「不会自动改后缀」的坑。

关于 format，官方有一条极容易踩的说明，原文如下：

「If format is set, it determines the output format, and the file is saved as fname. Note that fname is used verbatim, and there is no attempt to make the extension, if any, of fname match format, and no extension is appended.」

人话：fname 是原样使用的——matplotlib 不会帮你把扩展名改成跟 format 一致，也不会自动补扩展名。

而如果不设 format，规则是：

「If format is not set, then the format is inferred from the extension of fname, if there is one. If format is not set and fname has no extension, then the file is saved with rcParams["savefig.format"] (default: 'png') and the appropriate extension is appended to fname.」 
# 会存出一个叫 report.png 的 PNG（从扩展名推断）
fig.savefig("report.png")

# 会存出一个叫 report 的文件（无扩展名！），内容是 PNG
fig.savefig("report")

# 会存出一个叫 report.png 的文件，内容其实是 PDF —— 后缀在骗人
fig.savefig("report.png", format="pdf")

# 稳妥写法：扩展名和 format 一致
fig.savefig("report.pdf", format="pdf")

「后缀在骗人」这种文件交出去，最坑的是别人双击打不开，或者打开了发现是另一个东西。 做媒体工作尤其要在乎这个——一个后缀不对的图，可能在排版环节被当成 PDF 处理，直接崩掉。

另外两个常用的：

  • transparent：默认为 rcParams["savefig.transparent"]（False）。 填 True 时 Axes 的 patch 全部透明，Figure 的 patch 也透明（除非你用 facecolor/edgecolor 指定了）。 官方说这个「is useful, for example, for displaying a plot on top of a colored background on a web page.」—— 放在网页彩色背景上的图，用这个。 注意官方还说明透明设置在函数退出时会被还原，不会污染你的 figure。
  • pad_inches：默认 rcParams["savefig.pad_inches"]（0.1）。 「Amount of padding in inches around the figure when bbox_inches is 'tight'.」—— 只在 bbox_inches='tight' 时才生效，是紧包围盒外留的边距。 觉得 tight 切得太贴肉就调大它。

关于格式选择，还有一个官方在「Fonts in Matplotlib」里讲到的知识点，对印务很有用： PDF 和 PS 会把字体嵌进文件，所以别人电脑上没装你的字体也能正常显示，而且放大不会虚。 但完整嵌入 CJK 字体（字形特别多）会让文件非常大，所以 matplotlib 只嵌入实际用到的字形， 这叫 font subsetting（字体子集化）。所以你导出的中文 PDF 通常并不巨大。

官方另有一个 SVG 相关的参数值得一提：rcParams["svg.fonttype"] 默认 'path'， 也就是把字形转成矢量路径写进 SVG——好处是任何电脑打开都一样，代价是文字不可再编辑； 设成 'none' 则文字作为文本写在标记里，文件更小、文字可编辑，但显示效果会依赖观看方有哪些字体。

4.8 关键机制六：pandas 的 plot 和 matplotlib 的关系

官方 pandas 的「Chart visualization」文档开头就把关系说透了：

「We provide the basics in pandas to easily create decent looking plots.」
「The plot method on Series and DataFrame is just a simple wrapper around plt.plot().」

「Series 和 DataFrame 上的 plot 方法只是一个围绕 plt.plot() 的简单封装。」 这句话解释了两件你可能困惑的事：

  1. 为什么 df.plot() 的中文也是方块？因为它底层就是 matplotlib， 你设的 plt.rcParams['font.family'] 对它是生效的（前提是同一段脚本里设，且设在画图之前）。
  2. 为什么 pandas 文档说「我们只提供基础功能」？因为复杂定制必须回到 matplotlib 的 Axes 上去做。 官方在讲第三方库的 data.plot() 接口时也点明了这个出口：库把 Axes 还给你， 「understanding the explicit Axes interface, we could call: ax.set_title('My preferred title') to customize the title.」——理解显式 Axes 接口，你就能接着改标题。

pandas 画图的入口是 kind 参数，官方列出的取值：

kind 值图类型新闻里什么时候用
'bar' / 'barh'柱状图 / 水平柱状图比较几个类别的量（各部门发布量、各平台占比）。类别名长时用 barh
'hist'直方图看一个连续量的分布（稿件字数分布）
'box'箱线图看分布和异常值（各家媒体阅读量分布对比）
'kde' / 'density'密度图平滑版的分布曲线
'area'面积图看累积和构成变化
'scatter'散点图看两个量的关系（发布时长 vs 阅读量）
'hexbin'六边形分箱图散点太多糊成一团时的替代
'pie'饼图类别数 ≤ 5 时勉强可用，超过就别用

两种等价写法，官方说第二种更便于发现可用方法和它自己的参数：

df.iloc[5].plot(kind="bar")   # 写法一：kind 参数
df.plot.bar()                 # 写法二：df.plot.<kind> —— 在 Jupyter 里敲 df.plot. 再按 Tab 能列出全部

官方还列出了一张 Tab 补全的实际输出（说明还有这些方法可用）：

df.plot.area     df.plot.barh     df.plot.density  df.plot.hist     df.plot.line     df.plot.scatter
df.plot.bar      df.plot.box      df.plot.hexbin   df.plot.kde      df.plot.pie

另外，官方特别提醒了 pandas 绘图里一个「参数名不一致」的坑：

「Most pandas plots use the label and color arguments (note the lack of "s" on those). To be consistent with matplotlib.pyplot.pie() you must use labels and colors.」

人话：大多数 pandas 图用单数的 label / color， 但为了跟 matplotlib.pyplot.pie() 保持一致，饼图必须用复数的 labels / colors。 记错就会报 TypeError。

关于 pandas 图 x 轴日期的一个便利：官方说如果索引由日期组成，它会调用 gcf().autofmt_xdate() 尝试把 x 轴格式化成好看的样子。这就是为什么你直接 ts.plot()，日期轴往往已经斜排整齐了。

最后，pandas 还支持切换绘图后端（backend="backend.module" 或全局 pd.options.plotting.backend）， 可以换用 Bokeh、Altair、hvplot 等出交互图。不过官方文档对它的定位只是「可以扩展」， 这一节不展开；你要交静态图（报纸、PDF 报告），matplotlib 这条默认路线就够了。

4.9 一张图里放多个子图

官方给的创建 Figure 的常用方式（原文代码）：

fig = plt.figure()             # an empty figure with no Axes
fig, ax = plt.subplots()       # a figure with a single Axes
fig, axs = plt.subplots(2, 2)  # a figure with a 2x2 grid of Axes
# a figure with one Axes on the left, and two on the right:
fig, axs = plt.subplot_mosaic([['left', 'right_top'],
                               ['left', 'right_bottom']])

注意第二行和第三行的差别：subplots() 返回单个 ax， subplots(2, 2) 返回的是 axs（一个二维数组）， 得用 axs[0, 0]、axs[0, 1] 这样取。 如果你写 fig, ax = plt.subplots(2, 2) 然后 ax.plot(...)， 会报「numpy.ndarray 没有 plot 方法」这类错——因为 ax 现在是个数组。 这是新手特别容易犯的一个错，遇到时先看 subplots() 传了几个参数。

subplot_mosaic 那个写法很妙：用「字符串拼出来的布局图」决定排布， 重复出现的标签表示同一个 Axes 横跨多格（上例里 'left' 占左边整列，右边上下各一格）。 图上还能用字典按名字取：axd['upleft'].set_title('upleft')。 做「一主图 + 两侧小图」的新闻版式，这个比算坐标省事得多。

顺手记一个官方给的、很实用的「辅助函数」模式——把「往某个 ax 上画一种图」封装成函数，方便批量画：

def my_plotter(ax, data1, data2, param_dict):
    """
    A helper function to make a graph.
    """
    out = ax.plot(data1, data2, **param_dict)
    return out

data1, data2, data3, data4 = np.random.randn(4, 100)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(5, 2.7))
my_plotter(ax1, data1, data2, {'marker': 'x'})
my_plotter(ax2, data3, data4, {'marker': 'o'})
这个模式值得记下来：函数收一个 ax，往里画，返回结果。 因为你把「画哪儿」当参数传进去了，同一个函数可以复用到不同的 Axes 上，不会串图。 这正是显式接口的好处。官方在讲第三方库接口时也提到同样的思路——库的 plot 方法通常也接受一个可选的 ax 参数，让你把图放进自己安排好的位置。

4.10 边界：什么时候不该用 matplotlib

matplotlib 是静态图库，有它不擅长的领域。诚实地说清楚：

你想要的matplotlib 合适吗更合适的选择
报纸、PDF 报告里的静态图✅ 正合适—
网页上鼠标悬停看数值、可缩放❌ 不是它的强项Plotly、Bokeh、Altair（pandas 也支持换后端）
统计分布、回归拟合这类统计图⚠️ 能画，但要自己调不少seaborn（底层仍基于 matplotlib）
地图 / 空间数据❌ 不直接支持GeoPandas、folium；注意地图还涉及合规审查，不能随便用非标准地图数据
实时刷新的数据大屏❌ 不合适专门的 dashboard 工具

另外一个边界值得单独说：图不能替代统计判断。

把「三年投诉量上升」画成一条漂亮的上升折线，是非常容易的事；但这张图对不对，取决于 你算的是绝对数还是比例、口径有没有变、有没有把不同来源的数据混在一起。 matplotlib 会把任何数字画得很好看，它不会替你判断这些数字该不该放在一起比。 这是新闻绘图最要命的伦理问题，比任何技术参数都重要。

4.11 新手必踩的 10 个坑（错误 / 正确对照）

坑 1：中文全变方块

# ❌ 没设字体，中文标题是 □□□
import matplotlib.pyplot as plt
fig, ax = plt.subplots()
ax.set_title("投诉量变化趋势")
plt.show()

# ✅ 设 font.family，族名写在最前，末尾用 sans-serif 兜底
import matplotlib.pyplot as plt
plt.rcParams['font.family'] = ['Microsoft YaHei', 'SimHei', 'sans-serif']
fig, ax = plt.subplots()
ax.set_title("投诉量变化趋势")
plt.show()

# ✅ 或者只给这一个元素指定（作用范围只限于这处文字）
ax.set_title("投诉量变化趋势", family=['Microsoft YaHei', 'sans-serif'])

诊断口诀：中文变方块 + 英文数字正常 → 字体缺字形，去设 font.family，不要去找编码问题。

坑 2：先 show() 再 savefig()，存出空白图

# ❌ 存出一张空白图
plt.plot([1, 2, 3], [1, 4, 2])
plt.show()
plt.savefig("chart.png")

# ✅ 反过来
plt.plot([1, 2, 3], [1, 4, 2])
plt.savefig("chart.png")
plt.show()

# ✅ 最稳：用显式接口 + fig.savefig()
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 4, 2])
fig.savefig("chart.png")
plt.show()

坑 3：以为 savefig 会自动改后缀

# ❌ 存出一个叫 report 的文件（没有扩展名），内容是 PNG
fig.savefig("report")

# ❌ 存出一个叫 chart.png 的文件，内容其实是 PDF —— 后缀骗人，别人打不开
fig.savefig("chart.png", format="pdf")

# ✅ 后缀和 format 保持一致
fig.savefig("chart.pdf", format="pdf")

坑 4：把 Axes 当成「坐标轴」

# ❌ 以为 ax 是坐标轴，去找 x 轴对象却写错
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 4, 2])
# 想设 x 轴范围，写成对「轴」的操作 —— 其实 set_xlim 就在 ax 上
# ax.xaxis.set_xlim(...)  ← 绕远路，容易出错

# ✅ 记住 ax 是「绘图区」，范围直接设在 ax 上
ax.set_xlim(0, 4)
ax.set_ylim(0, 5)
# 真的要拿「刻度尺」时才用 ax.xaxis
ax.xaxis.set_ticks([1, 2, 3])

坑 5：subplots(2,2) 之后还用单数 ax

# ❌ ax 现在是个 2x2 的数组，没有 plot 方法
fig, ax = plt.subplots(2, 2)
ax.plot([1, 2, 3], [1, 4, 2])    # AttributeError

# ✅ 用 axs + 显式下标
fig, axs = plt.subplots(2, 2)
axs[0, 0].plot([1, 2, 3], [1, 4, 2])

# ✅ 只有一个子图时才用单数
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [1, 4, 2])

坑 6：不写 ax.legend() 却奇怪图例为什么没有

# ❌ 给了 label 但没有图例
fig, ax = plt.subplots()

# ✅ 显式调用 legend()
ax.legend()

# ⚠️ 如果只传了位置参数、没给 label，图例框会画出来但是空的
ax.plot([1, 2, 3], [1, 4, 2])            # 忘了 label=

# ✅ label 和 legend() 要配对出现

坑 7：dpi 当成「画质修复」用

# ❌ 一张 3x2 英寸的小图，靠调 dpi 想「变清晰」
fig, ax = plt.subplots(figsize=(3, 2))
ax.plot([1, 2, 3], [1, 4, 2])
fig.savefig("small.png", dpi=600)        # 只是把同样内容放大输出，线依然细

# ✅ 先给足画布尺寸，再按用途给 dpi
fig, ax = plt.subplots(figsize=(8, 4.5))   # 画布给够
ax.plot([1, 2, 3], [1, 4, 2])
fig.savefig("print.png", dpi=300, bbox_inches="tight")   # 印刷
fig.savefig("web.png",   dpi=150, bbox_inches="tight")   # 网页

# ❌ 标题太长、x 轴标签太长，直接被画布边缘裁掉
fig.savefig("chart.png")

# ✅ bbox_inches="tight" 自动算紧包围盒；嫌贴太紧就调 pad_inches

fig.savefig("chart.png", bbox_inches="tight", pad_inches=0.2)

# ✅ 老实 import pyplot（以及需要的 numpy）
import matplotlib.pyplot as plt

坑 10：数学符号不写 r 前缀

# ❌ \s 和 \n 会被 Python 当成转义序列，图形显示不对甚至报错
ax.set_title("$\sigma_i=15$")

# ✅ 加 r，表示原始字符串，反斜杠原样交给 matplotlib
ax.set_title(r"$\sigma_i=15$")

官方原话：「where the r preceding the title string signifies that the string is a raw string and that the backslash should not be interpreted as an escape character.」 （字符串前的 r 表示这是原始字符串，反斜杠不应被当作转义字符。） 这跟 regex 那节要加 r"..." 是同一个道理，可以对照着记。

5. 应用场景

场景一：把一份评论情绪数据，做成本地报纸能印的「情绪趋势图」

情形：你拿到某话题连续 12 周的评论情绪分值（-1 到 +1，负数代表负面）， 要交一张给版面的图——印在纸上，所以 dpi 要够、中文要正常、标题和轴标签不能被切掉。 

# -*- coding: utf-8 -*-
"""某话题 12 周情绪趋势图 —— 交付给版面"""
import matplotlib
import matplotlib.pyplot as plt

# ① 字体：族名写最前，末尾留兜底。Windows 上一般有微软雅黑和黑体
#    不确定有哪些字体时先跑：print(matplotlib.font_manager.get_font_names())
plt.rcParams['font.family'] = ['Microsoft YaHei', 'SimHei', 'sans-serif']

# ② 数据（真实场景里从 csv 读，见 file-io 那节）
weeks  = [f"第{i}周" for i in range(1, 13)]
score  = [0.12, 0.20, 0.05, -0.18, -0.42, -0.55,
          -0.38, -0.10, 0.08, 0.22, 0.31, 0.26]

# ③ 显式接口：拿到 fig 和 ax
fig, ax = plt.subplots(figsize=(8, 4.5))

ax.plot(weeks, score, marker="o", linewidth=2, color="#2c5a87",
        label="情绪分值（-1 极负 → +1 极正）")

# ④ 一条零基准线，让「正负」一眼可辨
ax.axhline(0, color="#999999", linewidth=1, linestyle="--")

# ⑤ 标题、轴标签、网格
ax.set_xlabel("时间")
ax.set_ylabel("情绪分值")
ax.set_title("某话题评论情绪 12 周走势")
ax.grid(True, alpha=0.3)
ax.legend()

# ⑥ x 轴标签竖排，防止 12 个「第N周」挤在一起
plt.setp(ax.get_xticklabels(), rotation=45, ha="right")

# ⑦ 先存文件，再显示（顺序不能反）
fig.savefig("情绪趋势_印刷版.png", dpi=300, bbox_inches="tight")
fig.savefig("情绪趋势_网页版.png", dpi=150, bbox_inches="tight")
plt.show()

这张图里每一行都在解决一个真实问题：

  • 字体那两行——不写就是 12 个方块中文。这是最优先的。
  • 零基准线 axhline(0, ...)——情绪数据有正有负，中间一条虚线能让读者立刻看出「哪几周转负」。 没有这条线，读者得自己去比对刻度，图的表达力立刻掉一半。
  • fig.savefig() 而不是 plt.savefig()——因为用显式接口拿到了 fig， 天然不会掉进「show 之后再存出空白图」的坑。
  • 存两版——印刷 300 dpi、网页 150 dpi。同一次运行出两个交付物，比事后手动转格式靠谱得多。
  • 两个都带 bbox_inches="tight"——「第1周～第12周」这排标签加上竖排， 很容易超出画布被裁掉，这个参数是必需的。
交付前必须人工检查的三件事（这一节最该记住的话）：
  1. 纵轴从 0 开始了吗？如果只画 0.05 到 0.31 这一段，视觉上会像「暴涨」，实际只动了 0.26。 情绪分值这种有明确 -1/+1 含义的指标，纵轴范围要老实标；如果为了看清变化而截断纵轴， 必须在图注里写明。这是图片编辑最常见也最严重的误导手法。
  2. 「第N周」的起止日期写了吗？图上的「第1周」对应哪个日历区间，图注里要交代。否则读者无法核对。
  3. 中文字体名在你同事的电脑上存在吗？如果你交出的是代码，换成他的机器可能又变方块（原因见 4.5）。 所以交出去的应该是图片文件，而不是只有代码；要给代码就附上「先跑 get_font_names() 确认」的说明。

场景二：从一张稿件数据表，出一张「各平台平均阅读量」柱状图

情形：你手上有一个 DataFrame（列：平台、阅读量、字数）， 要出一张三平台的对比柱状图。这类图直接用 pandas 最快，但因为要送排版（要自定义颜色、要标数值）， 所以走「pandas 画骨架 + matplotlib 补细节」的路子。 

# -*- coding: utf-8 -*-
"""各平台平均阅读量对比 —— pandas 画骨架，matplotlib 补细节"""
import pandas as pd
import matplotlib.pyplot as plt

# ① 字体必须在 df.plot() 之前设，否则第一张图还是方块
plt.rcParams['font.family'] = ['Microsoft YaHei', 'SimHei', 'sans-serif']

df = pd.DataFrame({
    "平台": ["A站", "B站", "C站", "A站", "B站", "C站"],
    "阅读量": [12000, 34000, 8000, 15000, 41000, 9000],
})

# ② 聚合：一定要先算出「平均值」再画，不能直接画原始行
avg = df.groupby("平台")["阅读量"].mean().sort_values(ascending=False)

# ③ 用显式接口拿 ax，把 pandas 的图画到指定的 ax 上
fig, ax = plt.subplots(figsize=(7, 4))
avg.plot(kind="bar", ax=ax, color="#2c5a87", rot=0,
         label="平均阅读量")

# ④ 回到 matplotlib 补细节（pandas 那层做不了这些）
ax.set_title("各平台平均阅读量对比")
ax.set_xlabel("平台")
ax.set_ylabel("阅读量（次）")
ax.grid(True, axis="y", alpha=0.3)      # 只画横向网格线，柱状图更好读
ax.legend()

# ⑤ 把数值标在柱顶——纸媒读者不用猜高度
#    注意 avg 经过 sort_values，顺序和 x 轴刻度一致
for i, v in enumerate(avg.values):
    ax.text(i, v + 800, f"{v:,.0f}", ha="center", fontsize=9)

# ⑥ 先把纵轴上限拉高一点，否则柱顶数字贴着画布边
ax.set_ylim(0, avg.max() * 1.15)

fig.savefig("平台阅读量对比.png", dpi=300, bbox_inches="tight")
plt.show()

几个关键点：

  • avg.plot(kind="bar", ax=ax, ...) 里的 ax=ax—— 这是把 pandas 的图「放进我指定的绘图区」。不传这个参数，pandas 会自己新建一张图， 你后面在 ax 上加的标题就加到了一个空的图上。 这是「pandas 直接画图」最核心的接口，也是混用两套体系时唯一安全的方式。
  • 先 groupby().mean() 再画——直接画原始 6 行会把同一个平台画成两根柱子，图就废了。 这是数据聚合问题（pandas 那节的内容），不是绘图问题，但画错图的人常常误以为是绘图没学会。
  • 只画横向网格 axis="y"——柱状图比较的是高度，横线帮忙读数，竖线只会添乱。
  • 柱顶标数值的 for 循环——enumerate 给出下标 i 当 x 坐标， ha="center" 让数字水平居中在柱子上。这一步让图从「能看」变「能读」。
  • set_ylim 留白——不留白的话，最高的那根柱子上的数字会被 bbox_inches="tight" 算进包围盒，导致图的比例变形（y 轴被压缩）。先手动抬高上限，图的纵向比例才稳定。
这张图必须配的图注信息：
  1. 「平均阅读量」的统计口径——是所有稿件的算术平均，还是去掉头部爆款后的平均？ 平均值极易被极端值拉偏，如果某个平台有几篇百万阅读的爆款，这个平均值就代表不了「一般稿子」的表现。 这种情况应该用中位数，或者同时给出两个数。
  2. 时间范围——哪段时间的数据。
  3. 样本量——每个平台各有多少篇稿件。3 篇算出来的平均和 3000 篇算出来的平均，可信度完全不同， 样本量太小时图注里必须标注，或者干脆不画。
  4. 颜色的含义——如果四个平台用了四种颜色，而颜色没有任何含义，那就是纯装饰； 如果颜色代表分组（比如自有平台 vs 外部平台），图注里要说清。

6. 概念辨析

辨析 1：Figure vs Axes vs Axis

FigureAxesAxis
中文该怎么理解整张图 / 画布一个绘图区坐标轴（刻度尺）
数量关系一个 Figure 可以含多个 Axes一个 Axes 通常含 2 个 Axis（3D 时 3 个）属于某个 Axes
典型操作fig.savefig()、fig.suptitle()、figsizeax.plot()、ax.set_title()、ax.legend()ax.xaxis.set_ticks()、Locator、Formatter
最容易搞混的地方以为 plt.figure() 就有坐标系了（其实没有，要 subplots()）以为 Axes 是「坐标轴」（这是最常见的错）以为 Axis 是所有轴的总称
 
fig = plt.figure()             # ❌ 只有一张空纸，没有绘图区
fig, ax = plt.subplots()       # ✅ 空纸 + 一个绘图区，这才画得出东西
fig, axs = plt.subplots(2, 2)  # ✅ 一张纸 + 四个绘图区

辨析 2：plt.plot() vs ax.plot()（隐式 vs 显式）

隐式 pyplot 接口显式 Axes 接口
写法plt.plot(x, y)fig, ax = plt.subplots(); ax.plot(x, y)
画在哪「它以为你想要的」那个对象上你明确指定的那个 ax 上
多个子图时要靠 plt.subplot() / plt.sca() 来回切，容易串图直接 axs[0].plot()，各画各的
官方态度方便（尤其交互式、简单脚本）「一般建议使用 OO 风格，特别是对于复杂图形，以及打算作为更大项目一部分复用的函数和脚本」
 
# 翻译规律：画图函数名字一样；取属性加 get_；设属性加 set_
plt.plot(x, y)              →  ax.plot(x, y)
plt.xlabel("时间")           →  ax.set_xlabel("时间")
label = plt.xlabel()        →  label = ax.get_xlabel()
plt.title("标题")            →  ax.set_title("标题")
关于「复用」这一条，官方讲得很直白：正因为 ax 是被显式传进去的， 你才能把「画一张图」封装成一个接受 ax 参数的函数（4.9 节的 my_plotter）。 隐式接口下写这种函数，函数里画的东西会跑到「当前轴」上去，调用两次就乱套了。

辨析 3：plt.show() vs plt.savefig()

show()savefig()
干什么显示所有打开的图（到窗口/前端）把当前图写成图片或矢量文件
关键副作用阻塞式调用结束时，图会被关闭并从 pyplot 注销无副作用（透明、facecolor 等设置退出时会还原）
顺序放最后放在 show 之前，或用 fig.savefig()
Jupyter 里可以省（后端每个 cell 结束自动调）要显式写，不会自动存
 
plt.savefig("a.png"); plt.show()      # ✅ 文件正常
plt.show(); plt.savefig("a.png")      # ❌ 存出空白图
fig.savefig("a.png"); plt.show()      # ✅ 更稳，不依赖顺序

辨析 4：plt.subplots() vs plt.subplot()

subplots()（带 s）subplot()（不带 s）
返回fig, ax 元组（多子图时 fig, axs 数组）一个 Axes 对象
是否创建 Figure会，一次创建好纸和所有绘图区不会，在已有的当前 Figure 上切一块
参数含义subplots(行数, 列数)subplot(行数, 列数, 第几个)
推荐度推荐（一次拿全，便于后面回头改）临时探索可用；回头改旧轴时很别扭
 
fig, axs = plt.subplots(1, 2)     # ✅ 一次拿全，后面 axs[0]/axs[1] 随便改
axs[0].plot([1, 2, 3], [1, 4, 2])
axs[1].plot([1, 2, 3], [3, 1, 2])

plt.subplot(1, 2, 1)              # ⚠️ 后面想改第一个轴，得重新 subplot(1,2,1) 切回去
plt.plot([1, 2, 3], [1, 4, 2])

辨析 5：font.family vs font.sans-serif（中文设置的两个位置）

这两个都出现在官方文档里，但它们不是同一层的东西：

font.familyfont.sans-serif
是什么「用哪些字体族」的有序列表「sans-serif 这个通用族名具体对应哪些字体」的映射表
可以放什么具体字体族名 和/或 通用族名（'serif'、'sans-serif' 等）具体字体族名列表
官方推荐改哪个推荐改这个：「prepend the font name to 'font.family' (recommended)」另一种等价做法（「第二种方法」）
 
# 方法一（官方推荐）：中文字体名塞进 font.family 最前面
plt.rcParams['font.family'] = ['Microsoft YaHei', 'sans-serif']

# 方法二：改通用族名的映射表
plt.rcParams['font.family'] = ['sans-serif']
plt.rcParams['sans-serif'] = ['Microsoft YaHei', 'sans-serif']

为什么两者等价？因为官方说明了替换规则：font.family 里出现通用族名时，会被原地展开成对应 rcParam 里的那一串具体字体（见 4.4 节的例子）。所以方法一里的 'sans-serif'，最终就是展开成 font.sans-serif 里的内容。既然结果一样，就用官方推荐的方法一，行数更少。

辨析 6：df.plot() vs matplotlib 的 ax.plot()

df.plot()（pandas）ax.plot()（matplotlib）
本质官方明说：「just a simple wrapper around plt.plot()」底座
输入直接吃 DataFrame/Series，自动拿索引当 x 轴、列名当图例吃序列（列表、数组、Series）
擅长快速出一张「decent looking」的基础图，几行搞定一切定制：样式、标注、多子图、精确控制
怎么配合用它画骨架，并传 ax= 指定目标绘图区接着在同一 ax 上补细节
 
fig, ax = plt.subplots(figsize=(7, 4))
avg.plot(kind="bar", ax=ax, rot=0)   # ✅ pandas 画骨架，落到我指定的 ax 上
ax.set_title("各平台平均阅读量对比")   # ✅ matplotlib 补细节
ax.grid(True, axis="y", alpha=0.3)

avg.plot(kind="bar")                 # ⚠️ 不传 ax：pandas 自己新建一张图
plt.title("标题")                     # 这张图的标题确实会加对，但你拿不到 ax，复杂定制寸步难行
官方对 pandas 绘图的定位是「提供基础功能」：「We provide the basics in pandas to easily create decent looking plots.」，并且明确把「超越这些文档范围的可视化」指向生态系统页面。 所以看到「pandas 画的图不够好看、不能定制」时，答案不是换库，而是「回到 matplotlib 的 Axes 上继续做」。

7. 自测问题

Q1：我画出来的中文标题是一排方块，但数字和英文正常。这是编码问题吗？
不是编码问题，是字体里没有这些汉字的字形。官方原文说得很清楚：从 v2.0 起默认字体 DejaVu 包含了「many western alphabets, but not other scripts, such as Chinese, Korean, or Japanese」。 渲染时找不到字形，就画个空心方框占位。修法是把中文字体族名加到 font.family 最前面，末尾留 'sans-serif' 兜底。判断口诀：中文全方块 + 英文数字正常 = 字体问题，不要去找编码问题。 （反过来，如果是一串 \xe6\x8a\x95 这种，那才是 file-io 那节的编码问题。）
Q2：为什么官方建议用 fig, ax = plt.subplots(); ax.plot(...) 而不是 plt.plot(...)？
三个理由。① 隐式接口把 Artist 加到「它以为你想要」的对象上，多图时容易串； ② 回头想改一个不在 plt.gca() 里的旧轴时，隐式接口要么重复 subplot 要么存 handle 再用 sca() 切回去，官方评价第一种是「quickly becomes inelegant」； ③ 有了 fig 之后可以用 fig.savefig()，顺手绕开 「show 之后再 savefig 存出空白图」的坑。官方总结：显式的起步啰嗦一点，但复杂图形往往更简单。
Q3：我第一次跑代码是这样，存出来是一张全白的图，为什么？ 
plt.plot([1, 2, 3], [1, 4, 2])
plt.show()
plt.savefig("chart.png")
因为阻塞式 show() 结束时，图被关闭并从 pyplot 注销了。 之后 pyplot.savefig() 去找「当前图」找不到，就新建了一张空图，于是你存下一张白板。 官方原文：「At the end of (a blocking) show() the figure is closed and unregistered from pyplot. Calling pyplot.savefig afterwards would save a new and thus empty figure.」 两种修法：把 savefig 挪到 show 前面；或者保留 fig 引用、改用 fig.savefig()（这条不受顺序限制）。
Q4：我要把图印在报纸上，dpi 和 bbox_inches 该怎么填？为什么光调 dpi 没用？
印刷一般 dpi=300，网页 dpi=150（dpi='figure' 是默认，表示用图自身的 dpi）。 bbox_inches="tight" 一定要加——它算出紧凑包围盒，解决「标题/轴标签被裁掉」， 官方定义是：「Bounding box in inches: only the given portion of the figure is saved. If 'tight', try to figure out the tight bbox of the figure.」；嫌贴太紧可以配 pad_inches。

光调 dpi 没用，因为 dpi 是「每英寸点数」，它决定的是同样内容输出多少像素。 你把一张 figsize=(3, 2) 的小图用 dpi=600 导出，得到的只是一张更大的、线条依然很细的图—— 它不会凭空多出细节。正确顺序是先给足 figsize，再按用途给 dpi。
Q5：savefig("chart.png", format="pdf") 会存出什么？
存出一个名叫 chart.png、内容其实是 PDF 的文件。 官方原文：「If format is set, it determines the output format... Note that fname is used verbatim, and there is no attempt to make the extension, if any, of fname match format, and no extension is appended.」——fname 原样使用，matplotlib 不会帮你把后缀改成和 format 一致，也不会补后缀。

这个坑还有个变体：savefig("report") 不设 format、也没有扩展名时， 文件会没有扩展名，内容按 rcParams["savefig.format"]（默认 'png'）保存， 并且会自动补上对应的扩展名——所以这种情况其实会存成 report.png。 记法：后缀和 format 一致，是最省心的做法。
Q6：df.plot(kind="bar") 画出来的中文也是方块，pandas 是不是要单独设字体？
不需要单独设。pandas 的 plot 官方明说只是「a simple wrapper around plt.plot()」， 底层就是 matplotlib，所以你设的 plt.rcParams['font.family'] 对它一样生效。

但有两个前提：① 设字体要在 df.plot() 之前（rcParams 是运行时全局状态）； ② 要在同一个 Python 进程里设——如果你在 Jupyter 里重启了内核，得重跑设字体的那行。 排查时如果「明明设了还是方块」，先检查这两条。
Q7：我想把「画一张柱状图」写成一个函数，以后复用。怎么写才安全？
让函数接收一个 ax 参数，往里画，然后返回结果。官方在快速入门里给了这个模式： 
def my_plotter(ax, data1, data2, param_dict):
    out = ax.plot(data1, data2, **param_dict)
    return out

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(5, 2.7))
my_plotter(ax1, data1, data2, {'marker': 'x'})
my_plotter(ax2, data3, data4, {'marker': 'o'})
关键在 ax 是参数而不是从「当前轴」里捞的。 如果函数内部写 plt.plot(...)（隐式接口），它就会画到「当前轴」上——调用两次可能都画到同一个轴上， 或者跑到你没预期的图上。官方讲第三方库接口时也是同样的思路：库的 plot 方法通常接受可选的 ax 参数， 让你把图放进自己安排好的位置，并把 Axes 还给你以便继续定制。
