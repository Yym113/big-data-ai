1 · 个人理解（先说人话）

列表就是一个能装很多东西的抽屉，而且有编号。你要取第 3 个，就说「第 3 个」，不用给每个东西起名字。 

titles = [
    "AI 重塑新闻业",
    "短视频平台算法争议",
    "县级融媒体的三年",
]

它和字符串最大的区别是：列表可以改。字符串是印好的报纸，列表是白板 —— 能擦、能加、能删、能排序，而且改完之后还是同一个列表，不是新建的。 

titles.append("第四个标题")
print(len(titles))       # 4  ← 同一个列表变长了

正因为它能改，就埋了 Python 里最有名的一个坑： b = a 不会复制列表，只是给同一个抽屉贴了第二张标签。 你改 b，a 也变 —— 因为它们本来就是同一个东西。 

a = [1, 2, 3]
b = a              # 不是复制！a 和 b 指向同一个列表
b.append(4)
print(a)           # [1, 2, 3, 4]  ← a 也变了

c = a[:]           # 这才是复制（切片整份或者用 a.copy()）
c.append(5)
print(a)           # [1, 2, 3, 4]  ← 这次 a 没变
一句话记住：列表能改，赋值不复制。记住这两条，你就躲开了列表 90% 的坑。

2 · 学习目标

学完这份资料，你应该能：

  1. 用索引、切片、负索引取出列表中的任意元素或片段，并说清切片「不含尾部」；
  2. 熟练使用 append / extend / insert / remove / pop / clear / index / count，并知道哪些返回 None；
  3. 区分 list.sort()（原地排序，返回 None）与 sorted()（返回新列表），并会用 key= 排序；
  4. 解释 b = a 与 b = a[:] 的区别，并说明什么时候必须显式复制；
  5. 识别并避免 [[None] * 2] * 3 这类「共享同一个内层列表」的多维列表陷阱；
  6. 说出在循环里删列表元素为什么危险，并给出正确写法。

4 · 结构化解释

4.1 定义

列表（list）：可变序列。官方文档的说法是「通常用来存储同类项的集合」。 和字符串相比，它多了一层「能被修改」的能力，也多了一堆修改方法。

官方列出的四种构造方式：

[]                    # 空列表
[a, b, c]             # 直接列举
[x for x in iterable] # 列表推导式
list(iterable)        # 类型构造器，例如 list("abc") → ['a','b','c']

4.2 最小模型：一排带编号的格子

titles = ["AI 重塑新闻业", "算法争议", "县级融媒体"]
# 索引:        0               1            2
# 负索引:     -3              -2           -1
# 长度 len(titles) = 3

索引和切片规则与字符串完全一样（都是序列）：从 i 到 j 的切片是「索引 k 满足 i <= k < j 的所有项」。 

nums = [0, 1, 2, 3, 4, 5]

nums[2:5]    # [2, 3, 4]   ← 不含索引 5
nums[:3]     # [0, 1, 2]
nums[3:]     # [3, 4, 5]
nums[:]      # [0, 1, 2, 3, 4, 5]   ← 浅拷贝，最常用的复制写法
nums[::2]    # [0, 2, 4]
nums[::-1]   # [5, 4, 3, 2, 1, 0]   ← 反转
nums[-2:]    # [4, 5]               ← 最后两个

# 切片还能赋值（字符串做不到！）
nums[1:3] = [88, 99]
print(nums)  # [0, 88, 99, 3, 4, 5]

4.3 类比

概念类比说明
列表带编号的抽屉柜按编号取，不用给每个东西起名字
索引 a[i]拉开第 i 个抽屉从 0 开始；-1 是最后一个
切片 a[i:j]一次拉开 i 到 j 前一个抽屉尾部不含（i <= k < j）
append往抽屉柜最后加一格原地操作，返回 None
sort()把柜子里的东西重新码一遍原地排序，返回 None
b = a同一个柜子贴两张标签改一处两处都变；不是复制
b = a[:]照原样买了一个新柜子两边独立；但里面的东西还是共享的（浅拷贝）
[[None]*2]*3三张标签贴在同一个抽屉上往任意一层放东西，三层都变

4.4 核心方法一览（含返回值）

方法作用返回值等价写法（官方给出）
append(x)末尾加一项Nonea[len(a):] = [x]
extend(it)把可迭代对象的所有项追加进来Nonea[len(a):] = it
insert(i, x)在位置 i 插入Nonea[i:i] = [x]
remove(x)删除第一个值为 x 的项None找不到抛 ValueError
pop([i])删除并返回位置 i 的项（默认最后一个）被删的那一项空列表或越界抛 IndexError
clear()清空Nonedel a[:]
index(x[,s[,e]])返回 x 首次出现的索引索引找不到抛 ValueError
count(x)统计 x 出现次数次数—
sort(*, key, reverse)原地排序None见辨析 3
reverse()原地翻转None官方明确：it returns None
copy()浅拷贝新列表a[:]
官方教程专门强调过这件事：「你可能已经注意到 insert, remove 或 sort 等仅修改列表的方法都不会打印返回值 —— 它们返回默认值 None。这是适用于 Python 中所有可变数据结构的设计原则。」 
nums = [3, 1, 2]
sorted_nums = nums.sort()          # ❌ 经典错误
print(sorted_nums)                 # None ← 不是排序后的列表！

nums.sort()                        # ✅ 原地排序，不要接返回值
print(nums)                        # [1, 2, 3]

# 想要一个新的排序结果，用内置函数 sorted()
new = sorted([3, 1, 2])            # ✅ 返回新列表
print(new)                         # [1, 2, 3]

4.5 sort() 与 key=

官方说明：sort() 是原地排序，只使用项之间的 < 比较； 接受两个仅限关键字参数 —— key（单参数函数，用于从每个元素中提取比较键）和 reverse。 并且它保证稳定：不改变比较结果相等的元素的相对顺序。 

# 按浏览量从大到小排序新闻
news = [
    {"标题": "AI 写稿", "浏览": 12800},
    {"标题": "县级融媒体", "浏览": 3400},
    {"标题": "算法争议", "浏览": 21000},
]

news.sort(key=lambda n: n["浏览"], reverse=True)
for n in news:
    print(n["标题"], n["浏览"])
# 算法争议 21000
# AI 写稿 12800
# 县级融媒体 3400

# 按标题长度排序
titles = ["AI 写稿", "县级融媒体的三年", "算法"]
titles.sort(key=len)
print(titles)     # ['算法', 'AI 写稿', '县级融媒体的三年']

# 稳定性：先按浏览量排，再按来源排，同来源内部仍保持浏览量的顺序
news.sort(key=lambda n: n["浏览"], reverse=True)
news.sort(key=lambda n: n.get("来源", ""))
官方还提醒：并非所有数据都能排序或比较。例如 [None, 'hello', 10] 不可排序， 因为整数不能与字符串比较、None 不能与其他类型比较。用 sort() 排一个混了 None 或混合类型的列表会直接抛 TypeError。

4.6 赋值不复制：最重要的一个机制

a = [1, 2, 3]
b = a              # 同一个对象，两个名字

b.append(4)
print(a)           # [1, 2, 3, 4]
print(a is b)      # True  ← 完全同一个对象

# 官方 FAQ 的说法：
# 「变量只是指向对象的一个名称。执行 y = x 并不会创建列表的副本。」

官方 FAQ 给出一张判断表，值得记下来：

写法是否改变原对象
y.append(10) / y.sort()改变原对象（原地操作）
y = y + [10] / sorted(y)不改原对象，创建新对象
a_list += [1, 2, 3]改变原列表（等价于 extend）
some_tuple += (1, 2, 3)元组不可变，创建新对象
 
# 想要真正独立的副本，三种写法（都只是浅拷贝）
b = a[:]
b = a.copy()
b = list(a)

# 嵌套结构必须用 deepcopy，否则内层还是共享的
import copy
deep = copy.deepcopy(a)

4.7 多维列表的经典陷阱：[[None] * 2] * 3

官方文档在讲 s * n 时专门用一段警告这件事： 序列中的项不会被复制，而是被多次引用。 

# ❌ 错误写法
lists = [[]] * 3
print(lists)              # [[], [], []]
lists[0].append(3)
print(lists)              # [[3], [3], [3]]   ← 一行改，三行全变

# 原因：[[], [], []] 里的三个 [] 是同一个空列表的三个引用

# ✅ 正确写法：用列表推导式，每次都新建
lists = [[] for _ in range(3)]
lists[0].append(3)
lists[1].append(5)
lists[2].append(7)
print(lists)              # [[3], [5], [7]]
# 做二维表格（比如 3 行 2 列的计数矩阵）时
rows, cols = 3, 2

bad = [[0] * cols] * rows          # ❌ 三行其实是同一行
bad[0][0] = 1
print(bad)                         # [[1, 0], [1, 0], [1, 0]]  全变了

good = [[0] * cols for _ in range(rows)]   # ✅
good[0][0] = 1
print(good)                        # [[1, 0], [0, 0], [0, 0]]

# 注意：内层 [0] * cols 是安全的，因为 0 是不可变的
# 危险只发生在内层的元素本身可变时 —— 比如 [[]] * 3

官方 FAQ「如何创建多维列表」条目明确写了：[[None]*2]*3 是错误的（引用共享）， 应使用列表推导式 [[None]*w for i in range(h)]。

4.8 循环中修改列表：为什么危险

官方教程原话：「很难正确地在迭代多项集的同时修改多项集的内容。更简单的方法是迭代多项集的副本或者创建新的多项集。」 

# ❌ 错误：边遍历边删，会跳过元素
nums = [1, 2, 2, 3, 2, 4]
for n in nums:
    if n == 2:
        nums.remove(n)
print(nums)          # [1, 2, 3, 4]  ← 少删了一个 2！

# 原因：删除后后面的元素前移，迭代器却继续往后走，漏看了一个

# ✅ 方案一：倒着删（索引不会错位）
for i in range(len(nums) - 1, -1, -1):
    if nums[i] == 2:
        del nums[i]

# ✅ 方案二（官方推荐）：创建新列表
nums = [n for n in nums if n != 2]

# ✅ 方案三：整体切片替换（官方 FAQ 给出的写法）
nums[:] = [n for n in nums if n != 2]
# 字典同理，官方教程给的写法是「迭代副本」
users = {'Hans': 'active', 'Éléonore': 'inactive', '景太郎': 'active'}
for user, status in users.copy().items():     # copy() 是关键
    if status == 'inactive':
        del users[user]
print(users)   # {'Hans': 'active', '景太郎': 'active'}

4.9 列表当栈用（顺带认识队列）

官方教程指出：列表方法让「后进先出」的栈用起来非常容易 —— 入栈用 append()，出栈用 pop()。 

stack = [3, 4, 5]
stack.append(6)
stack.append(7)
stack.pop()      # 7  最后进的先出
stack.pop()      # 6
print(stack)     # [3, 4, 5]

# 反过来当队列（先进先出）用列表是低效的 —— 官方明确说了：
# 「在列表开头插入或弹出条目却很慢（因为所有其他元素都必须移动一位）」
from collections import deque
queue = deque(["Eric", "John", "Michael"])
queue.append("Terry")
queue.popleft()   # 'Eric'
queue.popleft()   # 'John'
print(queue)      # deque(['Michael', 'Terry'])

5 · 应用场景

场景一：把抓来的新闻列表做筛选、排序、去重

news = [
    {"标题": "AI 写稿工具上线", "浏览": 12800, "来源": "科技日报"},
    {"标题": "县级融媒体三周年", "浏览": 3400,  "来源": "新闻战线"},
    {"标题": "算法推荐争议调查", "浏览": 21000, "来源": "科技日报"},
    {"标题": "AI 版权第一案", "浏览": 9600,  "来源": "法治日报"},
    {"标题": "短视频平台治理", "浏览": 21000, "来源": "新闻战线"},
]

# 1. 筛选浏览量过万的（创建新列表，不原地删）
hot = [n for n in news if n["浏览"] >= 10000]
print(len(hot))                     # 3

# 2. 按浏览量降序、浏览量相同则按标题排
hot.sort(key=lambda n: (-n["浏览"], n["标题"]))
for n in hot:
    print(f'{n["浏览"]:>6}  {n["标题"]}')
#  21000  短视频平台治理
#  21000  算法推荐争议调查
#  12800  AI 写稿工具上线

# 3. 统计有哪些来源（去重后排序）
sources = sorted({n["来源"] for n in news})
print(sources)                      # ['法治日报', '新闻战线', '科技日报']

# 4. 追加新抓到的条目
news.append({"标题": "AI 主播出镜", "浏览": 4200, "来源": "科技日报"})
print(len(news))                    # 6

# 5. 找出浏览量最高那条的下标
views = [n["浏览"] for n in news]
top_idx = views.index(max(views))
print(news[top_idx]["标题"])

key=lambda n: (-n["浏览"], n["标题"]) 用了元组比较：先比第一个，相同再比第二个。 -n["浏览"] 是为了让浏览量降序。这个技巧在排序新闻列表时非常常用。

场景二：清洗一批标题并做长度分布统计

标题长度是内容分析里常见的指标（比如「短视频标题是不是越来越短」）。用列表先做完清洗，再统计分布。 

raw = [
    "  AI 重塑新闻业 - XX新闻网  ",
    "短视频平台算法争议调查｜独家",
    "县级融媒体",
    "  生成式 AI 的版权问题：训练数据从哪里来  ",
    "算法",
]

def clean(t):
    t = t.strip()
    for sep in (" - ", "｜"):
        if sep in t:
            t = t.split(sep)[0]
    return t.strip()

cleaned = [clean(t) for t in raw]
# ['AI 重塑新闻业', '短视频平台算法争议调查', '县级融媒体',
#  '生成式 AI 的版权问题：训练数据从哪里来', '算法']

lengths = [len(t) for t in cleaned]
print("最短：", min(lengths), " 最长：", max(lengths))
print("平均：", sum(lengths) / len(lengths))

# 分桶统计：短（<=5）/ 中（6-15）/ 长（>15）
buckets = {"短": 0, "中": 0, "长": 0}
for L in lengths:
    if L <= 5:
        buckets["短"] += 1
    elif L <= 15:
        buckets["中"] += 1
    else:
        buckets["长"] += 1
print(buckets)     # {'短': 2, '中': 1, '长': 2}

# 挑出最长的 3 条（sorted 不动原列表）
for t in sorted(cleaned, key=len, reverse=True)[:3]:
    print(len(t), t)
注意这里用的是 sorted(cleaned, ...) 而不是 cleaned.sort(...) —— 前者返回新列表、不动原数据，后者会把 cleaned 本身改掉。做探索性分析时优先用 sorted()，误伤概率更低。

6 · 概念辨析

辨析 1：remove vs pop vs del

写法按什么删返回值找不到时
a.remove(x)按值删第一个匹配NoneValueError
a.pop(i)按索引删被删的那个元素IndexError
del a[i]按索引删无（是语句）IndexError
a.clear() / del a[:]全删None—
 
a = ["甲", "乙", "丙", "乙"]

a.remove("乙")     # 只删第一个 "乙"
print(a)           # ['甲', '丙', '乙']

a.remove("丁")     # ValueError: list.remove(x): x not in list

b = ["甲", "乙", "丙"]
x = b.pop()        # 删并返回最后一个
print(x, b)        # 丙 ['甲', '乙']
y = b.pop(0)       # 删并返回第 0 个
print(y, b)        # 甲 ['乙']

c = ["甲", "乙", "丙"]
del c[1]
print(c)           # ['甲', '丙']
要「删掉并且还想拿到」就用 pop；只是想删掉就用 del； 只知道值不知道位置用 remove。remove 最容易踩的坑是「它只删第一个」—— 列表里有多个重复值时，一次 remove 只干掉一个。

辨析 2：sort() 返回 None，不是排序结果

nums = [3, 1, 2]

# ❌ 最常见的错误
nums = nums.sort()
print(nums)          # None   ← 列表被改了，但返回的是 None，反手把它赋给了 nums

# ✅
nums = [3, 1, 2]
nums.sort()          # 原地排
# 或者
nums = sorted([3, 1, 2])   # 新列表

同样的坑还有 reverse()（返回 None）、append()（返回 None）。 官方教程把它总结为：仅修改列表的方法都返回 None，这是所有可变数据结构的设计原则。

辨析 3：b = a vs b = a[:]

a = [1, 2, 3]

b = a
b.append(4)
print(a, b)          # [1, 2, 3, 4] [1, 2, 3, 4]   一起变

a = [1, 2, 3]
c = a[:]
c.append(4)
print(a, c)          # [1, 2, 3] [1, 2, 3, 4]      独立了

print(a is c)        # False  不同的对象
print(a == c)        # False  内容也不同

但 a[:] 只是浅拷贝。如果列表里装的是列表，内层仍然共享： 

a = [[1, 2], [3, 4]]
b = a[:]              # 外层复制了
b.append([5, 6])      # 这行不会影响 a ✅
b[0].append(99)       # 这行会影响 a ❌
print(a)              # [[1, 2, 99], [3, 4]]

# 完全隔离要用 deepcopy
import copy
a = [[1, 2], [3, 4]]
c = copy.deepcopy(a)
c[0].append(99)
print(a)              # [[1, 2], [3, 4]]   安全

辨析 4：append vs extend vs +

a = [1, 2]

a.append([3, 4])
print(a)              # [1, 2, [3, 4]]   ← 整个列表当成一项塞进去

a = [1, 2]
a.extend([3, 4])
print(a)              # [1, 2, 3, 4]     ← 拆开逐项追加

a = [1, 2]
a += [3, 4]
print(a)              # [1, 2, 3, 4]     ← += 对列表等价于 extend（原地）

a = [1, 2]
a = a + [3, 4]
print(a)              # [1, 2, 3, 4]     ← + 创建新列表，原对象不变
+= 和 + 只差一个等号，行为却完全不同： 官方 FAQ 指出 a_list += [1, 2, 3] 会修改原列表（等同 extend）， 而 a = a + [1, 2, 3] 是创建新对象。在有其他变量指向同一个列表时，这个区别会造成 bug。

辨析 5：append("abc") vs extend("abc")（字符串是序列）

a = []
a.append("abc")
print(a)              # ['abc']          一项，内容是字符串

a = []
a.extend("abc")       # 字符串也是可迭代的！
print(a)              # ['a', 'b', 'c']  被拆成了三个字符

# 想追加一个字符串而不要拆开，用 append
# 想按字符拆开，用 extend 或 list()

辨析 6：list.sort(key=...) 的 key 只能传函数名，不能直接传值

news = [{"浏览": 100}, {"浏览": 300}, {"浏览": 200}]

# ❌ 想当然的写法
news.sort(key=news["浏览"])       # TypeError: list indices must be integers...
news.sort(key="浏览")              # 不报错，但比较的是所有元素都相同的字符串 —— 结果无意义

# ✅ 用 lambda 提取键
news.sort(key=lambda n: n["浏览"])
print([n["浏览"] for n in news])   # [100, 200, 300]

# ✅ key 也可以是内置函数名
titles = ["aaa", "a", "aa"]
titles.sort(key=len)               # [a, aa, aaa]

官方教程在讲 lambda 时给的正是一个 sort(key=...) 的例子： pairs.sort(key=lambda pair: pair[1])。

7 · 自测问题

Q1：a = [0,1,2,3,4,5]，a[1:3] 是什么？为什么不是 3 个元素？
[1, 2]。切片定义是「索引 k 满足 i <= k < j」，尾部不包含， 所以取的是索引 1 和 2。
Q2：nums = [3,1,2]，执行 nums = nums.sort() 后 nums 是什么？
None。sort() 原地排序并返回 None，赋值后原来的列表被丢弃了。 正确写法是 nums.sort()（不接返回值）或 nums = sorted(nums)。
Q3：a = [1,2,3]; b = a; b.append(4)，此时 a 是什么？为什么？
[1, 2, 3, 4]。b = a 不复制数据，两个名字指向同一个列表对象。 官方 FAQ：「变量只是指向对象的一个名称。」想隔离要用 a[:] 或 copy.deepcopy()。
Q4：lists = [[]]*3; lists[0].append(1) 的结果是什么？怎么改才对？
结果是 [[1], [1], [1]] —— 三个元素是同一个列表对象的引用。 正确写法：lists = [[] for _ in range(3)]（官方 FAQ 推荐）。
Q5：remove 和 pop 的区别是什么？
remove(值) 按值删第一个匹配项，返回 None，找不到抛 ValueError； pop(索引) 按索引删，返回被删的元素，越界抛 IndexError。
Q6：为什么不能在 for n in nums 里直接 nums.remove(n)？
删除会让后面的元素前移，但迭代器仍在按位置往后走，导致某些元素被跳过。 官方建议「迭代多项集的副本或者创建新的多项集」，实用写法是 nums = [n for n in nums if 条件] 或倒着遍历删除。
Q7：a.sort(key=len) 里的 key 是干什么的？
key 是一个单参数函数，用来从每个元素中提取「比较键」，排序时只比较这些键。 官方说明：每个元素的键只计算一次，然后用于整个排序过程。写法上通常配合 lambda： news.sort(key=lambda n: n["浏览"])。
