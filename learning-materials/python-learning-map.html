字典 · 元组 · 集合 · 嵌套结构

上半场 45 min · 字典
  • 为什么需要字典：一条新闻有标题、来源、时间、正文 —— 用列表记不住谁是谁
  • 创建 news = {"标题": "...", "来源": "..."}、取值 news["标题"]
  • 安全取值 get()、增改 news["新键"] = 值、删除 del
  • 遍历：for k, v in news.items()
  • 重点：列表套字典 —— [{"标题": ...}, {"标题": ...}]，这是后面 CSV 和 JSON 的标准形态
下半场 45 min · 元组 / 集合 / 嵌套
  • 元组 (1, 2, 3)：不可修改，用于「不该被改的数据」
  • 集合 {1, 2, 3}：自动去重 —— 统计「有几个不同来源」时很好用
  • 嵌套：字典里放列表、列表里放字典，多层结构怎么取值
  • 三种结构的选用速查表

要写出来的代码

# 列表套字典：一次存多条新闻（这是最重要的结构）
news_list = [
    {"标题": "AI 重塑新闻业", "来源": "新华社", "浏览": 12800},
    {"标题": "暴雨引发内涝", "来源": "本地日报", "浏览": 3400},
]

for n in news_list:
    print(n["来源"], "·", n["标题"])

# 集合去重：有几个不同来源
sources = {n["来源"] for n in news_list}
print("来源数：", len(sources))
为什么学这个：CSV 读进来是表，JSON 读进来是字典，AI 模型的输出也常是字典。「列表套字典」是数据世界最通用的形状，必须练熟。
课后必做：用「列表套字典」表示 5 条新闻（含标题/来源/浏览三列），遍历打印，并统计有多少个不同来源。

要写出来的代码

titles = ["AI 重塑新闻业", "暴雨引发内涝", "大模型进入内容审核", "新能源汽车销量创新高"]

# 筛选
for t in titles:
    if "AI" in t or "大模型" in t:
        print("科技类：", t)

# 累加器：统计总字数
total = 0
for i, t in enumerate(titles):
    total += len(t)
print("平均标题长度：", total / len(titles))
为什么学这个：「批量处理」是编程的核心价值。手工筛 10 条标题没意义，但筛 10 万条就必须靠循环。循环 + 判断 = 你后面做一切数据处理的骨架。

函数

上半场 45 min · 函数基础
  • 为什么需要函数：同一段逻辑写第二遍就该封装
  • 定义与调用：def 函数名(参数): → return 结果
  • 参数与返回值；没有 return 时返回 None
  • 把课 4 的筛选逻辑封装成 filter_titles(titles, keyword)
下半场 45 min · 函数进阶
  • 默认参数 def f(x, sep=" ")（注意：默认参数别用可变对象）
  • 关键字参数调用 f(sep=",", x=data)
  • 返回多个值：return a, b（其实是返回元组）
  • 作用域：局部变量 vs 全局变量；为什么函数里改不动外面的列表
  • 函数文档字符串 """说明"""

要写出来的代码

def filter_titles(titles, keyword):
    """返回所有包含 keyword 的标题"""
    result = []
    for t in titles:
        if keyword in t:
            result.append(t)
    return result

def title_stats(titles):
    """返回标题总数和平均长度"""
    if not titles:
        return 0, 0
    total = sum(len(t) for t in titles)
    return len(titles), round(total / len(titles), 1)

hit = filter_titles(["AI 新闻", "暴雨内涝", "AI 审核"], "AI")
print(hit)
print(title_stats(hit))
为什么学这个：后面的 AI 课，你几乎不会从零写算法，都是调用现成的函数。会写函数，才能看懂别人写的函数；def f(x): ... return y 这个形式必须一眼看穿。
课后必做：写 3 个自己的工具函数（筛选标题 / 统计词数 / 格式化成表格行），存成一个 my_tools.py。

推导式 + 内置函数（写得更少，做得更多）

上半场 45 min · 列表推导式与 lambda
  • 列表推导式：[t for t in titles if "AI" in t] —— 三行循环变一行
  • 带条件、带运算的推导式
  • 字典推导式 {k: v for ...}（了解即可）
  • lambda：lambda x: len(x) —— 临时用一次的小函数
  • 什么时候不该用推导式：逻辑超过一层，就老老实实写循环
下半场 45 min · 常用内置函数
  • len / sum / max / min / abs / round
  • sorted(data, key=..., reverse=True) —— 按指定规则排序，实战高频
  • map() / filter()：批量转换 / 批量筛选
  • zip()：把两个列表配对
  • any() / all()：判断「有没有满足的」/「是不是都满足」

要写出来的代码

news_list = [
    {"标题": "AI 重塑新闻业", "浏览": 12800},
    {"标题": "暴雨引发内涝", "浏览": 3400},
    {"标题": "大模型进入内容审核", "浏览": 9600},
]

# 推导式筛选
ai_news = [n for n in news_list if "AI" in n["标题"] or "大模型" in n["标题"]]

# 按浏览量倒序排（key 指定排序依据）
hot = sorted(news_list, key=lambda n: n["浏览"], reverse=True)

for n in hot:
    print(n["浏览"], n["标题"])
为什么学这个：sorted(key=lambda ...) 是 pandas 排序的底层逻辑；推导式是 pandas 筛选的底层逻辑。先在小数据上把这两招练成肌肉记忆，第 12 课的 pandas 会轻松很多。
课后必做：把课 4 的 20 条标题任务，用推导式 + sorted 重写一遍，对比代码长度。

文件读写（TXT / CSV / 编码）

上半场 45 min · 文本文件与编码
  • open("a.txt", "r", encoding="utf-8") 读 / "w" 写 / "a" 追加
  • with open(...) as f: 写法 —— 自动关闭文件，永远用这个
  • 读全部 read() / 读一行 readline() / 按行遍历 for line in f
  • 中文编码三大坑：UnicodeDecodeError → 加 encoding="utf-8"；还报错试 gbk；Windows 记事本存 UTF-8 会带 BOM，用 utf-8-sig
下半场 45 min · CSV 读写
  • 用标准库 csv 读：csv.reader / csv.DictReader（推荐后者，直接得字典）
  • 写 CSV：csv.writer / DictWriter；newline="" 防止多空行
  • 把「列表套字典」存成 CSV，再从 CSV 读回「列表套字典」
  • 用 Excel 打开 CSV 中文乱码 —— 这是 Excel 的问题，不是你的代码问题（用「数据→从文本导入」选 UTF-8）

要写出来的代码

import csv

# 写：列表套字典 -> CSV
news_list = [
    {"标题": "AI 重塑新闻业", "来源": "新华社"},
    {"标题": "暴雨引发内涝", "来源": "本地日报"},
]
with open("news.csv", "w", encoding="utf-8-sig", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["标题", "来源"])
    writer.writeheader()
    writer.writerows(news_list)

# 读：CSV -> 列表套字典
with open("news.csv", encoding="utf-8-sig") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["来源"], "·", row["标题"])
为什么学这个：这是本阶段最关键的一课。后面的 AI 课程里，数据永远以文件形式存在（CSV / TXT）。「把数据读进来 → 处理 → 存出去」，这个闭环打通了，你才算真的会用 Python。
课后必做：手工做一份 20 行的新闻 CSV（标题/来源/浏览），用 Python 读进来，筛选+排序后，存成一个新文件。全程不打开 Excel 编辑。

上半场 45 min · 异常处理
  • 异常是什么：程序出错就抛异常，不处理就崩
  • try / except 基本结构；捕获特定异常 except FileNotFoundError:
  • 常见异常类型：FileNotFoundError / KeyError / IndexError / ValueError / TypeError

# 读文件时做好防护
try:
    with open("news.csv", encoding="utf-8") as f:
        content = f.read()
except FileNotFoundError:
    print("文件不存在，请检查路径：", "news.csv")

# 调试：把中间状态打出来
news = {"标题": "AI 新闻"}

正则表达式（文本清洗的利器）

上半场 45 min · 正则基础
  • 正则解决什么问题：按「模式」而不是「精确内容」查找和替换
  • re 模块四个函数：search / findall / sub / split
  • 元字符入门：\d 数字、\w 单词字符、\s 空白、. 任意字符
  • 量词：* + ? {2,5}；字符集 [abc]、[^abc]
  • 中文范围 [\u4e00-\u9fa5]（记这一个就够）
下半场 45 min · 正则实战
  • 清洗四件套：去标点、去多余空白、去 HTML 标签、去 URL
  • 提取：从文本里抓出所有数字 / 日期 / 邮箱
  • 把清洗逻辑封装成函数 clean_text(s)
  • 正则的坑：r"..." 原始字符串为什么要加 r

要写出来的代码

import re

text = "【重磅】AI 重塑新闻业！详见 https://example.com 阅读 12800 次
"

# 1. 去 HTML 标签
text = re.sub(r"<.*?>", "", text)
# 2. 去网址
text = re.sub(r"https?://\S+", "", text)
# 3. 去标点（保留中文和字母数字）
text = re.sub(r"[^\w\u4e00-\u9fa5]", "", text)

print(text)                    # 重磅AI重塑新闻业详见阅读12800次
print(re.findall(r"\d+", text))  # ['12800']
为什么学这个：真实世界的新闻文本全是「脏」的 —— 带标签、带推广语、带特殊符号。不洗干净，后面的分词、统计、建模全部失真。正则就是那把刷子。
课后必做：准备 10 条「带杂质」的标题（含网址、话题标签、emoji、多余空格），写一个清洗函数把它们统一成干净文本。

numpy：数值批量运算

上半场 45 min · 数组基础
  • 为什么需要 numpy：Python 列表做 10 万次运算很慢，numpy 快几十倍
  • 创建数组：np.array([1,2,3]) / np.zeros(5) / np.arange(10) / np.linspace(0,1,5)
  • 核心特性：向量化运算 —— arr * 2、arr + arr 直接对每个元素生效，不用写循环
  • 形状 shape、维度 ndim、类型 dtype
  • 二维数组（矩阵）：行、列的概念
下半场 45 min · 索引与统计
  • 索引与切片：arr[0]、arr[0:5]、二维 arr[0, 1]、arr[:, 0]（取一列）
  • 布尔索引（重点）：arr[arr > 100] —— 这就是 pandas 筛选的底层原理
  • 统计函数：mean / std / max / min / sum / median
  • 按轴运算 axis=0 / axis=1（知道含义即可）

要写出来的代码

import numpy as np

# 10 条新闻的浏览量
views = np.array([12800, 3400, 9600, 21000, 1500, 7800, 43000, 2200, 6600, 11000])

# 向量化运算：不用写循环
print("万为单位的浏览量：", views / 10000)

# 布尔索引：筛出爆款
print("爆款标题位置：", np.where(views > 10000))

# 统计
print("均值", views.mean(), "中位数", np.median(views), "最高", views.max())
为什么学这个：numpy 是所有数据科学和 AI 库的地基 —— pandas 建立在它上面，所有机器学习模型的内部运算都是 numpy 数组。「布尔索引」这一招，学通了 pandas 筛选就不用背。
课后必做：造一组 30 个浏览量数字，用 numpy 算出均值/中位数/标准差，筛出高于均值的部分，并算出它们占比。

import pandas as pd

df = pd.read_csv("news.csv", encoding="utf-8-sig")

print(df.shape)          # (200, 4)
print(df.head())         # 看前 5 行

# 四板斧
hot = df[df["浏览"] > 10000]                        # 筛选
top10 = df.sort_values("浏览", ascending=False).head(10)   # 排序
by_source = df["来源"].value_counts()                # 计数

卡住时的自救流程（按顺序做）

  1. 先完整读完报错，尤其最后一行和 Traceback 里的文件名+行号。
  2. 高频错误对照表：
    报错关键词大概率原因怎么改
    UnicodeDecodeError读文件没指定编码加 encoding="utf-8"，还错试 gbk 或 utf-8-sig
    ModuleNotFoundError库没装 / 装错环境pip install 库名；检查是不是装到了另一个 Python 环境
    FileNotFoundError路径不对确认文件和脚本同目录，或用绝对路径
    KeyError字典里没这个键先 print(d.keys()) 看有什么；用 get() 兜底
    IndexError下标超范围检查 len()，注意下标从 0 开始
    IndentationError缩进不一致统一用 4 个空格，别混 Tab
    图表中文方块没设中文字体plt.rcParams["font.sans-serif"] = ["SimHei"]
  3. 还没解决：打印中间变量，确认数据到哪一步变得「不是你以为的样子」。
  4. 最后才问人/AI，提问带上：我的目标 + 完整代码 + 完整报错 + 已经试过什么。
