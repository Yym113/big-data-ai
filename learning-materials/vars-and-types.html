1 · 个人理解（先说人话）

变量不是什么高深的玩意儿。它就是一个贴了名字的盒子，你把数据放进去，之后用名字去找它。 

title = "AI 重塑新闻业"

这一行做了两件事：先造出一个盒子装着字符串 "AI 重塑新闻业"，再在盒子上贴一张写着 title 的标签。 以后你写 title，Python 就去这个盒子里把东西拿出来。

「数据类型」是这个盒子的形状。同样是「1」，写成 1 是一个能加减的数字，写成 "1" 是一段不能做算术的文字。 盒子形状不对，东西就装不进去、也算不出来 —— 这是新手 90% 报错的真正原因。

一句话记住：变量是名字，类型是形状。你后面处理新闻数据遇到的所有问题，本质上都是「我以为是 A 形状，实际是 B 形状」。

2 · 学习目标

学完这份资料，你应该能：

  1. 说出变量赋值的本质，并解释「= 不是数学里的等于」；
  2. 识别 Python 四种最基本的类型（int / float / str / bool），看到一个字面量能说出它的类型；
  3. 用 type() 检查任意数据的类型，并解释为什么要检查；
  4. 在类型之间安全转换（int() / float() / str() / bool()），并知道什么情况下转换会失败；
  5. 遵守命名规则，写出不会踩坑的变量名。

4 · 结构化解释

4.1 定义

变量：指向某个对象的名称。在 Python 中，变量本身不「装有」数据，它只是指向内存里一个对象的名字（引用）。

数据类型：对象的类别，决定了这个对象支持哪些操作。例如 str 支持拼接和切片，int 支持加减乘除。

4.2 最小模型：赋值语句发生了什么

views = 12800
# 1. 右侧先求值：造出一个整数对象 12800
# 2. 左侧的名字 views 指向这个对象

views = 13000
# 名字 views 改指向一个新的整数对象 13000
# 原来的 12800 对象没人指向了，之后被回收
关键点：= 是「贴标签」，不是「数学等于」。 a = a + 1 在数学里是矛盾的，在 Python 里完全是合法操作 —— 因为它的意思是「让 a 这个标签改指向一个新算出来的值」。

4.3 类比

概念类比说明
变量贴了名字的收纳盒用名字取东西，不用记它放在第几排
数据类型盒子的形状方形盒子装不进圆形物体："abc" + 1 就是这个错
type()拿起盒子看一眼形状不确定时先看清楚再操作
类型转换把内容倒进另一个形状的盒子有可能倒不进去（int("abc") 直接报错）

4.4 四种基本类型（关键机制）

类型写法例子用途注意点
int 整数 12800 -5 0 计数、条数、浏览量 精度无限，不会溢出
float 浮点数 3.14 1.0 1e3 比例、平均值、概率 存在精度误差（见 4.5）；1e3 就是 1000.0
str 字符串 "新闻" 'abc' 文本、标题、来源 不可修改；引号内的数字仍是字符串
bool 布尔 True False 条件判断、开关标记 是 int 的子类，True == 1 成立

类型决定运算规则

1 + 1          # 2        int + int = int
1 + 1.0        # 2.0      int + float = float（int 被"拓宽"为 float）
"1" + "1"      # "11"     字符串拼接
"1" + 1        # TypeError！字符串不能和整数相加

# 除法永远是浮点数
6 / 2          # 3.0  注意是 3.0 不是 3
6 // 2         # 3    // 是整除（向下取整）
-1 // 2        # -1   向下取整不是向零取整

4.5 浮点数精度：为什么 0.1 + 0.2 != 0.3

0.1 + 0.2 == 0.3        # False
0.1 + 0.2               # 0.30000000000000004

原因：计算机用二进制存小数，而十进制的 0.1 在二进制里是无限循环小数（就像十进制的 1/3 = 0.333… 永远写不完）。 存储时只能截取前 53 位，于是得到一个「非常接近但不等于」0.1 的值。

这不是 Python 的 bug，也不是你代码的问题 —— C、Java、JavaScript 全都这样，因为硬件就是这么实现的（IEEE 754 标准）。 官方文档明确指出：Python 浮点数映射为 IEEE 754 binary64 双精度值，只有 53 位精度。 
# 正确做法：比较时用容差，不要用 ==
import math
math.isclose(0.1 + 0.2, 0.3)      # True

# 需要精确十进制（如金额）时用 decimal 模块
from decimal import Decimal
Decimal("0.1") + Decimal("0.2") == Decimal("0.3")   # True

# 显示时格式化即可，不用改存储
print(f"{0.1 + 0.2:.2f}")          # 0.30

4.6 类型转换

int("123")       # 123      字符串 → 整数
int(3.9)         # 3        截断小数部分，不是四舍五入！
float("3.14")    # 3.14
str(456)         # "456"
bool(0)          # False
bool("")         # False    空字符串为假

# 会失败的转换
int("abc")       # ValueError: invalid literal for int()
int("3.14")      # ValueError！要先 float("3.14") 再 int()

bool() 的规则：以下值一律为 False —— None、False、 所有数值零（0 / 0.0）、空序列和空集合（"" / [] / {} / () / set()）。其余为 True。

4.7 命名规则

规则说明例子
可用字符字母、数字、下划线；不能数字开头news_1 ✅   1news ❌
大小写敏感Title 和 title 是两个变量踩坑高发区
不能用关键字35 个保留字，见下class / for / if ❌

避开易混字符不用单个 l / O / I会和 1 0 看混
常量模块级常量全大写 + 下划线MAX_COUNT

Python 的 35 个关键字（不能用作变量名）：

False      await      else       import     pass
None       break      except     in         raise
True       class      finally    is         return
and        continue   for        lambda     try
as         def        from       nonlocal   while
assert     del        global     not        with
async      elif       if         or         yield

另有「软关键字」match / case / _ / type， 仅在特定语法上下文中被当作关键字，作普通变量名仍可用（但建议避开）。

4.8 一个必须提前知道的坑：赋值是引用，不是拷贝

a = [1, 2, 3]
b = a            # 没有复制！b 和 a 指向同一个列表
b.append(4)
print(a)         # [1, 2, 3, 4]  ← a 也变了
官方文档原话：「Python 中的简单赋值绝不会复制数据。」 对于数字、字符串这类不可变对象感觉不出来（因为改的时候是新建对象），但列表、字典这类可变对象一定会出问题。 想真正复制：b = a[:] 或 import copy; b = copy.deepcopy(a)。

5 · 应用场景

场景一：读取新闻数据时的类型陷阱（最常见）

你从 CSV 读进来一批新闻，想算平均浏览量。CSV 里所有内容读出来默认都是字符串，直接求和会报错或得到错误结果。 

import csv

with open("news.csv", encoding="utf-8-sig") as f:
    rows = list(csv.DictReader(f))

# 错误写法：字符串相加
total = sum(r["浏览"] for r in rows)      # TypeError 或拼成一长串

# 正确写法：先转换类型
total = sum(int(r["浏览"]) for r in rows)
print("平均浏览量：", total / len(rows))

# 不确定时先探一下类型
print(type(rows[0]["浏览"]))              # <class 'str'>

这正是 学习地图里第 1 课强调「先搞清楚手上是什么类型的数据」的原因。

场景二：给新闻打标时的布尔值

做内容分析时经常要标记「这条是不是爆款」，用 bool 直接存判断结果，比存 "是"/"否" 字符串更好用（能直接统计数量、能做筛选）。 

news = {"标题": "AI 重塑新闻业", "浏览": 12800}

# 存布尔值，而不是字符串
news["是否爆款"] = news["浏览"] > 10000
print(news["是否爆款"])        # True

# 布尔能直接参与统计（True 就是 1）
all_news = [{"浏览": 12800}, {"浏览": 3400}, {"浏览": 21000}]
hot_count = sum(n["浏览"] > 10000 for n in all_news)
print("爆款条数：", hot_count)   # 2

6 · 概念辨析

辨析 1：= vs ==

= 是赋值（贴标签），== 是比较（判断值是否相等）。写错是新手最高频的语法错误之一。

a = 1        # 把 1 贴到 a 上
a == 1       # True，问「a 的值是 1 吗」

辨析 2：is vs ==

is 判断是不是同一个对象（身份），== 判断值是否相等。 

a = [1, 2, 3]
b = [1, 2, 3]
a == b       # True   内容一样
a is b       # False  但不是同一个对象

c = a
a is c       # True   同一个对象

x = None
x is None    # 这是判断 None 的推荐写法（PEP 8）
不要用 is 比较数字或字符串的值 —— Python 并不保证小整数和字符串是单例。 官方文档明确列出「可放心用 is」的只有三种情况：赋值后、放入容器后、以及 None 这类单例。

辨析 3：int 截断 vs 四舍五入

int(3.9)       # 3   截断小数部分
round(3.9)     # 4   四舍五入
int(-3.9)      # -3  截断是「向零取整」
round(-3.9)    # -4

处理浏览量、条数这类整数指标时，想清楚要的是截断还是舍入。

辨析 4：/ vs //

7 / 2      # 3.5   普通除法，结果总是 float
7 // 2     # 3     整除，向下取整
-7 // 2    # -4    向下取整（不是 -3！）

辨析 5：字符串 "1" vs 数字 1

从文件、网页、输入框拿到的数据永远是字符串。这是数据处理的头号类型陷阱。 

1 + 1        # 2
"1" + "1"    # "11"
"1" + 1      # TypeError: can only concatenate str (not "int") to str

辨析 6：浮点不等式的来源（易被误判为 bug）

0.1 + 0.2 != 0.3 常被当成 Python 缺陷。它不是 —— 官方文档专门用一章说明这是二进制浮点的本质特性， 并指出「你会在所有支持硬件浮点运算的语言中发现同样的情况」。 需要精确计算用 decimal；需要比较用 math.isclose()。

7 · 自测问题

Q1：a = 1 之后执行 a = a + 1，为什么这不是数学上的矛盾？
因为 = 是赋值不是相等判断。先算右侧 a + 1 得到新值 2，再让名字 a 改指向这个新对象。
Q2：写出下面三个值的类型：100、"100"、100.0。
int、str、float。带引号的数字也是字符串，这是最典型的类型陷阱。
Q3：1 + 1.0 的结果是什么类型？为什么？
结果是 2.0（float）。混合运算时较窄的类型会被拓宽 —— 官方文档：若有浮点则另一个转浮点数。
Q4：int("3.14") 会成功吗？怎么做才对？
不会，抛 ValueError。要先 float("3.14") 再 int()，即 int(float("3.14")) 得到 3。
Q5：b = a 之后修改 b，什么情况下 a 也会变？
当 a 指向可变对象（如列表、字典）时。官方文档：「Python 中的简单赋值绝不会复制数据。」想隔离要用 a[:] 或 copy.deepcopy()。
Q6：0.1 + 0.2 == 0.3 的结果？该怎么正确处理？
False（实际值 0.30000000000000004）。用 math.isclose() 比较；需要精确十进制时用 Decimal 模块。
Q7：为什么不能把变量命名为 class 或 for？
它们是 Python 的 35 个保留关键字之一，被语言本身占用。可用 keyword.kwlist 打印完整列表。
