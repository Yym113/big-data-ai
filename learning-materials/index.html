概念之间的联系（跨概念的坑）

下面这些坑不属于某一个概念，只有把几个概念放在一起看才会暴露出来。考试和实际写代码时最容易栽在这里。

联系 1：变量赋值是引用 —— 跨「变量 / 列表 / 字典」

变量与类型+ 列表+ 字典

b = a 不复制数据。对不可变对象（数字、字符串）看不出问题，但对列表和字典会造成「改一个另一个也变了」。 详见 变量与类型 · 辨析 2 和 列表 · 赋值陷阱。

联系 2：类型决定运算 —— 跨「变量 / 字符串 / 文件读写」

变量与类型→ 字符串→ 文件读写

从文件读出来的数据全是字符串。"12800" + "3400" 得到 "128003400" 而不是 16200。 这是数据处理第一号陷阱，必须养成「先 int() 再算」的习惯。

联系 3：循环 + 条件 + 累加器 —— 跨「循环 / 条件 / 变量」

循环+ 条件判断+ 变量

total = 0 开一个累加器 → 循环遍历 → if 筛出想要的 → total += 值。 这个四步模式是所有统计代码的骨架，后面统计词频、算平均值全靠它。

联系 4：推导式是循环 + 条件的简写 —— 跨「推导式 / 循环 / 条件」

循环+ 条件判断→ 推导式

[t for t in titles if "AI" in t] 等价于「建空列表 → 循环 → 判断 → append」。 理解不了推导式就把它展开成循环；反过来，看到循环 + append 就该想到能不能改写成推导式。

联系 5：pandas 是 numpy + 字典 + 循环的思想集合 —— 跨「numpy / 字典 / 推导式 / pandas」

字典+ numpy+ 推导式→ pandas

df[df["浏览"] > 10000] 是 numpy 布尔索引的思路；df["标题"] 取一列像字典按键取值； groupby 本质上是「循环 + 字典累加」。前三样学扎实，pandas 不用背语法。

联系 6：文件读写是数据进出的唯一入口 —— 跨「文件读写 / pandas / matplotlib」

文件读写→ pandas→ matplotlib

不管后面用什么高级工具，数据永远以文件形式存在。read_csv 帮你省掉手写 open 的活， 但底层就是课 09 学的东西 —— 包括那个绕不过去的中文编码问题。
